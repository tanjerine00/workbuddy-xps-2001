## 保留的经验：Vosk（2026-09-11 工具已删，知识仍可用；自项目 MEMORY.md 移入）

### 1. 安装
- `pip install vosk`。官方只发 4 个 wheel：`win_amd64`、`manylinux_2_12_x86_64`、
  `manylinux2014_aarch64`、`linux_armv7l`。Windows 包是 `py3-none` 通用包，**Python 3.13 可用**。
- **Windows 必须 64 位 Python**，32 位至今不支持。arm64 官方没上 PyPI，只能 GitHub Releases 手装 `.whl`。
- 源码编译要先构建 Kaldi（openblas/openfst），Windows 官方建议 mingw 交叉编译，坑极多，不建议。
- 国内换源：`-i https://pypi.tuna.tsinghua.edu.cn/simple`。

### 2. 模型下载（最大的坑）
- **API 与模型分离**，pip 装完只是库，模型必须单独下。
- 官方源 `alphacephei.com` 实测只有 **~48KB/s**，42MB 小模型下了约 17 分钟。
- 必须断点续传：`curl -L --fail -C - -o model.zip <url>`（实测中途断过一次，接上了）。
- 国内镜像 hf-mirror / modelscope / gitee / gh-proxy / ghfast.top 全部探测不通，**没有可用加速源**。

### 3. 音频格式硬约束（最关键）
- 必须 **16kHz / 16bit / 单声道 PCM**。格式不对的表现是**输出为空**，不是报错——最容易误判。
- 不要自己写转码，交给 ffmpeg 流式输出：`ffmpeg -loglevel error -i IN -ar 16000 -ac 1 -f s16le -`。
  mp3 / m4a / mp4 抽音轨 / opus / 44.1k 立体声 wav 实测全可用。
- 日志用 `-loglevel error` 别用 `quiet`（quiet 把排错信息一起吞掉）。
- 前置体检（文件存在 / ffmpeg 存在 / ffprobe 有无音轨）放在加载模型**之前**，避免白等。
- 空结果只有两种真实原因：模型语言与音频语言不匹配、或音频里确实没人说话。

### 4. 识别接口（流式，三个返回值）
```python
from vosk import Model, KaldiRecognizer, SetLogLevel
SetLogLevel(-1)                    # 关掉 Kaldi 刷屏日志
model = Model(model_dir)           # 循环外只建一次！加载要几秒
rec = KaldiRecognizer(model, 16000)
if rec.AcceptWaveform(pcm_chunk): rec.Result()      # True = 一句话说完了
else: rec.PartialResult()                           # False = 取中间结果实时上屏
rec.FinalResult()                  # 收尾必调，否则丢最后一段话
```
- 中文模型输出词间不加空格；英文模型用空格分词。
