# 回测信号：显著性检验与口径自查

## 何时用

- 刚跑完一个「信号 → 事件 → 前向收益」的回测，准备写「超额 +X%、胜率 Y%」
- 用户问「这个信号靠谱吗 / 样本够不够 / 胜率 69% 高不高」
- 用户指出「单只标的、五年样本、N 个事件」这类软肋，要你解释严重到什么程度
- 你要从多个阈值档里挑一个「最好的」写进结论

## 铁律

1. **只报胜率和均值，等于没做检验**。必须补：t 检验、bootstrap CI、置换检验
2. **超额必须逐年/逐期匹配基准** —— 中位数也一样（最容易被忽略）
3. **绝对收益胜率 ≠ 策略边际**。两者必须同时报
4. 查不到/算不出的就写"算不出"，**不用估算填**

---

## 一、六层诊断清单（按严重程度，逐层给数字）

| 层 | 查什么 | 怎么给数字 |
|---|---|---|
| 1 | **样本量够不够** | 算 **MDE**，见 §三 |
| 2 | **事件真的独立吗** | 逐对检查事件间隔 < 前向窗口长度 → 有效独立样本 = n − 重叠对数 |
| 3 | **显著吗** | t 检验 + bootstrap CI + **置换检验**（§二） |
| 4 | **口径对吗** | 超额/中位数是否逐年匹配基准（§四） |
| 5 | **挑出来的吗** | 多重检验校正（§五） |
| 6 | **测的是什么** | 绝对收益 vs 同基准超额，分开报（§六） |
| 7 | **是「信号」还是「空间」** | 分开报「振幅/区间宽度」（原料）与「ρ(偏离, 未来收益)+CI」（信号）→ §4.5 |

## 二、置换检验（最干净的一条，优先做）

**问的问题**：如果**随机挑同样数量的日子**、用**同样的基准调整**，能不能也得到这个超额？

```python
# 前置：D=交易日列表, C=收盘价, fwd[d]=T+H 前向收益, base[year]=该年基准, idx={日期:序号}
def draw_nonoverlap(k, pool, gap=H):
    got = []
    while len(got) < k:
        d = random.choice(pool)
        if all(abs(idx[d] - idx[g]) >= gap for g in got):
            got.append(d)
    return got

null = []
for _ in range(5000):
    ds = draw_nonoverlap(n, pool)
    a = [fwd[d] - base[d[:4]] for d in ds]
    null.append(sum(a) / len(a))
null.sort()
p = sum(1 for x in null if x >= obs) / len(null)     # 单侧
```

- **必须带"非重叠"约束**，否则零分布偏乐观
- 至少 **5000 次**；同时给出零分布的 95 分位（比 p 值更直观）
- 同一套零分布可以顺手算中位数口径、胜率口径的 p

**为什么它比 t 检验好**：不假设正态。事件收益是右偏厚尾（会有 +44% 这种极值），
t 检验的前提本来就不成立。

## 三、MDE：把"样本不够"变成公式

```
MDE = (z_{1−α/2} + z_{1−β}) × σ / √n        # α=5% 双侧、检力 80% → 系数 1.96+0.84 = 2.80
要检出效应量 e 所需的 n = ((z_a + z_b) × σ / e)²
```

**读法**：观测到的效应**小于 MDE** 时，无论算得多准都**不可能**被判显著。
这不是"数据不干净"，是"样本量在物理上分辨不出来"。**必须写进报告。**

例：n=26、σ=13.96% → MDE = **7.67%**。而观测超额只有 +3.08% → 原理上就不可能显著。
反过来：想在 σ=13.96% 下检出 +3% 的效应，需要 **n ≈ 170**。

## 四、★ 口径自查：最隐蔽的一类错（务必逐条过）

### 4.1 超额必须逐年匹配基准
```python
# 对
exc_i = r20_i − base[year_i]          # base[year] = 该年所有交易日前向收益的均值
# 错（会把牛市年份的优势算成策略优势）
exc_i = r20_i − base[全样本]
```

### 4.2 中位数也要匹配 —— 最容易漏
```python
# 对
median_excess = median([r20_i − base[year_i] for i in events])
# 错（实质是「事件中位 − 全样本中位」，未剔年度效应）
median_based_wrong = median([r20_i]) − median([所有交易日 r20])
```
> **实例**：某回测报「中位数口径 +2.08%，不受极端值影响」，查代码发现是
> `事件中位 − 全样本中位`（+1.41% − (−0.67%) = +2.08%）。
> 而 26 个事件里 15 个落在牛市年份，拿它们比含熊市的全样本中位**必然偏高**。
> **逐年匹配后的正确值是 −1.22%** —— 结论从"典型超额为正"反转成"典型事件跑输"。

### 4.3 逐年"方向一致"要看分组大小
n=4~6 的分组里，"每年超额都为正"通常意味着**每年各有 1~2 个事件在撑**，
中位数可能 2 正 3 负。**分组方向一致性在这么大的分组里信息量接近于零。**

### 4.4 已知的连环陷阱
同一份回测里，同一个错误类会反复出现：**"口径混用让数字看起来更好"**。
看到"简单平均 / 全样本基准 / 未匹配中位数"这类字样就要警觉。
**修完一处，回头检查其他处是否同一病。**

### 4.5 ★「空间存在」不等于「信号存在」—— 波动类 / 降本类操作的前置检验

很多方案的隐含主张**不是**「预测方向」，而是「赚波动」：网格、分批摊薄、低吸高抛。
这类主张的**前置条件**是均值回归，必须**单独测**；不能因为「振幅很大」就默认它可行。

```python
# z = (C - MA60) / SD60      —— 价格相对自身近 60 日的标准化偏离
# 判据：Spearman(z, 未来 H 日收益) + bootstrap CI
#   ρ 显著为负 → 均值回归，分批有依据
#   ρ 显著为正 → 动量，分批方向反了
#   ρ ≈ 0（CI 跨 0）→ 分批既不赚也不亏，只是摊薄时点
# 解读强度：ρ = −0.13 → R² ≈ 1.7% ⇒ 几乎无解释力
```

**两个数必须分开报，否则一定自欺**：

| 数 | 说明什么 | **不能**推出什么 |
|---|---|---|
| 日均振幅 / N 日区间宽度 | **空间存在**（原料够） | 不代表有信号 |
| ρ(z, 未来收益) + CI | **信号有无** | 不显著 ⇒ 只能靠**固定规则**摊薄，不靠**择时** |

实测反例（中芯国际，653 / 668 交易日）：振幅中位 A股 **3.11%** / 港股 **4.49%**、
20 日区间宽度 **13.3%** / **18.2%**（**空间充足**）；但 ρ(A股, 20日) = **−0.127**（CI 不跨 0，**R²≈1.6%**）、
ρ(港股, 5日) = **0.000**（**信号几乎不存在**）⇒ 结论只能是「**降本靠规则化摊薄，不靠择时**」。

⚠ **还差一步才算完整**：交易成本（佣金 / 印花税 / 价差 / 冲击成本）**不在价量数据里**。
**没有它就不给收益率结论。** ★ 但要分清两种「查不到」：
① **费率** 是**交易所 / 监管公布的确定规则**（A股：佣金约 0.025% 双边 + 印花税 0.05% 卖出 + 过户费 0.001%；
　 港股：单边约 0.108%）→ **可以用**，但必须写明「**公开标准费率、非用户实际费率**」并提供覆盖入口；
② **冲击成本与滑点** 需要盘口深度，价量数据里**根本没有** → **查不到就写查不到**，
　 此时结论只能报**上界**（真实成本只会更差）。
**把①当成「没有数据」是过度保守，把②当成「可以估算」是自欺。**

### 4.6 ★ 把别人的方案「实现出来再测」，不要靠辩论评估

拿到一份看起来很专业的方案（三级漏斗 + 加权评分 + 置信度）时，**不要**逐条评论它对不对——
按它**自己声称的口径**，用你**已有**的数据**实现一遍**，然后跑 §一 的诊断。
实例：实现后得 109 个「事件」，表面读数「事件组 T+20 中位 **+6.40%** vs 基准 **+0.75%**」看着有效；
**去簇后只剩 8 / 7 个独立事件**，置换检验 **p = 0.2744 / 0.0520 → 不显著**。
**「表面读数有效」与「样本能分辨」是两件事。**

**顺带一条硬规矩：删掉所有无回测支撑的分数。**
`0–100 异动评分`、`★★★★★`、`置信度 91%` 都是**伪精确**：没有兑现时点、没有判对判错、无法回填
→ **永远无法被追责**。替代品是**三值归因状态**（`已归因·基本面` / `已归因·资金层面` / `未解释`），
并把「未解释」登记进带**四要素**（内容 / 兑现时点 / 判对 / 判错）的对账册，到期强制回填。

### 4.7 ★ 先检验「锚」本身稳不稳 —— 否则「偏离」在时间上不可比

任何「偏离中枢就行动」的方案，都隐含一个**几乎从未被检验的前提**：「围绕一个稳定锚点波动」。
这个前提**可以单独测**，而且经常不成立。

```python
# centers[i] = median(x[i-W : i])        —— 滚动中枢序列（W 取半年量级，如 120 日）
# drift = (P90(centers) - P10(centers)) / median(centers)
#   ★ 用 P90-P10 而非 max-min —— 后者会被单点极端值拉爆（典型自欺）
#   判据：drift < 15% 稳定 ／ < 40% 中等 ／ 否则 漂移（固定阈值不可用）
#   同时打印中枢序列的采样（每 60 日一个）—— 一眼看出是「持续漂移」还是「偶尔跳」
```

实测反例（中芯国际，653 交易日，窗口 120 日）：A/H 溢价漂移 **114.4%**、A股 PB **74.5%**、H股 PB **108.0%**
—— 中枢**单边移动**（A股 PB 2.50 → 6.31×、H股 0.83 → 3.28×）。
⇒ **固定阈值的中枢偏离规则不可校准**：在上行趋势里会持续误判为「高估」。

★ **还有一层比数值更致命的**：即使锚在长期是稳定的，「**判断锚有没有动**」**需要未来信息** ——
你只能**事后**知道某段下跌是「市场犯错」还是「锚在移动」。
**难点不在算法，在于它不可操作。** ⇒ 这类方案只能保留「偏离 → **归因**」，**不能**接「偏离 → **机会**」。

> 附：**比率锚优于绝对锚**。绝对估值需要增长率 / 折现率假设（假设会主导结论）；
> **比率锚**（如 `PB = 价格 ÷ 每股净资产`）的分母**随基本面自动上移** ——
> 「基本面在积累」被自动除掉，于是不需要先知道锚在哪。但**比率锚有盲区**：
> 落在**未来现金流**上的基本面变化（技术路线 / 监管 / 大客户）当期净资产还没动 → 比率锚看不见，
> 必须靠**事件锚**（人工）补。**两层必须都有。**

### 4.8 ★ 区分「结构性成本优势」与「方向性预测力」

「赚波动」类方案常把两件性质完全不同的事混在一起：**采样方式**与**方向判断**。

| | 结构性（采样方式） | 方向性（预测） |
|---|---|---|
| 例子 | 固定金额分批 vs 等股数买入 | 跌了买 / 涨了追 |
| 数学 | **`AM ≥ HM` 恒成立**（算术-调和不等式），**与价格过程无关** | 需要 ρ ≠ 0；实测常为 ρ ≈ 0 |
| 能否依赖 | **能**，但幅度 ∝ 波动率 | **不能** |
| 基准怎么选 | 必须用**窗口算术平均价**（= 随机时点一次性的期望成本），**不是**首日价 / 末日价 | — |

```python
# 固定金额分批的平均成本 = K / Σ(1/P_i) = HM(P)   —— 调和平均
# 等股数买入的成本       = mean(P)      = AM(P)   —— 算术平均
# AM >= HM 恒成立  ⇒  定投相对「随机时点一次性买入」有结构性优势
# 两个必须处理的反直觉点：
#   1) 优势 ∝ 波动率（实测 ρ(优势, 波动率) ≈ −0.85）
#   2) `AM >= HM` 是【零成本】恒等式；扣手续费后重算 ——
#      波动不够大时，结构优势会被手续费吃掉 ⇒ 会得到「更贵的比例」显著大于 0
```

**三条必须同时报**，否则会得出相反结论：

| 基准 | 说明什么 | 能不能当判据 |
|---|---|---|
| **vs 算术平均价** | **结构性优势在这里**（负值 = 占优） | ✅ **是判据** |
| vs 首日全买 / vs 末日全买 | 主要反映**样本趋势**（上涨窗口为正、下跌窗口为负） | ❌ **不是判据** |
| 相关系数 ρ(成本差, 波动率) | 验证机制（显著为负才说明「波动是原料」） | ✅ 是**机制检验** |

实测反例（中芯国际，593 个滚动窗口，60 交易日窗）：定投 vs 算术平均价 A股 **−1.282%** / 港股 **−1.506%**
（更贵的窗口仅 21.2% / 18.6%），ρ = **−0.872 / −0.836**；
而**「底仓 + 机动仓网格」12 个配置全部减股**（−1.95% ~ −4.70%，增股比例全 < 50%）。
⇒ **能省的是「买法的差价」，省不出「买点的差价」。**

⚠ **网格类策略的归因必须写边界**：全负的直接原因是**样本期单边重估**（网格在高点不断卖出 = 卖飞），
**不等于**「网格在任何市场都不行」。但**先决条件（接下来是单边还是震荡）无法事前判定** ——
这正是它不可作为规则的原因。

## 五、多重检验：你是从几个格子里挑的？

| 比较范围 | 比较次数 K | 至少一次假阳性 = 1 − 0.95^K |
|---|---|---|
| 只看一个周期 × 12 个信号 | 12 | 46% |
| × 6 个阈值档 | 72 | **97.5%** |
| × 3 个样本期 | 216 | ≈100% |

- Bonferroni 门槛：α/K。**26 次比较、α=0.05/72 时，需要 26/26 全赢才算显著**
- 更实用的替代：**预注册单一阈值**（先定，后跑），或 White's Reality Check / Hansen SPA
- **"唯一三周期均为正的档位"这句话本身就是挑选证据** —— 报告里必须写明是从多少格子里挑的

## 六、绝对收益 vs 同基准超额：必须分开报

同一份数据会出现两种截然不同的结论：

| 统计量 | 观测 | 随机日零分布 | p | 含义 |
|---|---|---|---|---|
| **绝对收益**胜率 | 69.2% | 95 分位 61.5% | **0.004** ✅ | 显著 —— 但这是"标的在涨" |
| **同基准超额**均值 | +3.08% | 95 分位 +3.97% | 0.098 ❌ | 不显著 |
| **同基准超额**中位 | −1.22% | — | ❌ | 方向为负 |

> 正确读法：**"择时到上涨阶段" ≠ "在同一阶段内提供超额"**。
> 标的长期上涨时，任何信号都会"看起来有效"——所以**必须报基准胜率做对照**。

## 七、报告模板（缺一项就不合格）

```
样本：n 个事件 / 有效独立样本 ≈ m（k 对前向窗重叠）
分布：均值、中位、sd、SE、极值
集中度：最大 3 个占合计的百分之几；剔除后均值是否翻负
显著性：t（p）、bootstrap 95%CI、置换检验 p + 零分布 95 分位
样本量：MDE = ?；要检出目标效应需 n ≈ ?
多重检验：从 K 个格子里挑 → 假阳性概率 = ?
分开报：绝对收益胜率 vs 同基准胜率
对照：不显著 → 结论只能写成「可能存在的弱倾斜」，不得写成期望值
```

## 八、常见坑

- 置换检验没加"非重叠"约束 → 零分布偏乐观
- bootstrap 只对收益重抽、忘了同步重抽年份基准 → 口径不一致
- **同一文件多处 Edit 并行会互相覆盖**（工具都报 success，实际只落一部分）
  → 用一次性幂等补丁脚本（marker 判已应用 + 命中次数断言 + 回读复核）
- **改过文件后锚点会失效**：`    }  ],` 可能已变成 `    }\n  ],`
  → 补丁脚本必须先核对当前锚点；命中 0 要**整体放弃**而不是写出半成品
- Python 格式化串里出现裸 `%`（如 `+2.08%）`）→ `TypeError: not enough arguments`，改用 f-string
- 手写 Student-t 尾概率（正则化不完全贝塔）可以免掉 scipy 依赖；**别为此硬装 scipy**
- **高频 / 分钟级通道多半不给历史**：先用**二分实测**确定回溯边界（例：2024-09-30 有 / 2024-09-02 空 ⇒ 滚动 ≈480 交易日），再决定能不能建域。
  **滚动窗口 = 数据会持续过期消失**，与「可复核的零缺口历史域」直接冲突；
  接口自述「不支持历史 / 不支持逐笔 / level2」要**当结论用**，不要试图绕。
- **只给当日的高频接口做不了「同时段基准化」**：基准要 N 日同一时段，只给当日就只剩 1 个样本。
