# 数学科普稿：出版级事实审校与概念边界校准

## 一句话结论

**审校意见本身也要核。** 正确顺序是「先回原文逐句核对 → 再独立核事实 → 最后分三类处理（采纳 / 修正后采纳 / 不采纳）」。
跳过第一步，就会照着转述改稿，改出一堆原稿里根本不存在的问题；跳过第二步，就会把审校者自己的错误也抄进书里
（实测：一份 26 条的审校意见里，24 处引文全部真实存在、约 20 条成立、**3 条不成立**，而审校者**漏掉了 1 处真错误**）。

### ★ 两个正交的轴，报告里要分开给数

| 轴 | 问什么 | 实测 |
|---|---|---|
| **引文准确性** | 他引的那句话，稿子里真有吗？ | 一章 24/26 命中；**四章 20/20 全对** |
| **判断有效性** | 就算引对了，他的判断成立吗？ | 二章 5/26 已达标或偏差；三章 14/20；**四章 11/19** |

**引文全对 ≠ 判断全对**，也 **≠ 判断无效**。四章那份 20 处引文零错引（前三份都有错引，它是真读过稿的），
可仍然有 **3 条判断偏差**——其中一条（"基数不是一条简单的直线"）若照办，会把一个**正确**的线性序说成非线性的。
⇒ 报告开头两句话就能交代完：「引文 N/N 命中」＋「必改 x／应改 y／可选 z／已达标 p／判断偏差 q」。

## 触发场景

- 用户贴来长篇审校/评审意见，问"看有没可取的地方，专业客观实事求是"。
- 自己写完数学史 / 科普章节，进入"出版级"自查阶段。
- 稿子里出现"这显然是…""不可能同时成立""第 N 次数学危机""某某说：…""他被这场争论耗尽了"这类强断言。

## 第 0 步（最容易被跳过）：回原文核对审校意见

审校者会把你的句子改写后再批评。**先把每一条的引文当字符串回原文检索**：

```python
import io, re
s = io.open(F, encoding='utf-8').read()
body = re.sub(r'<(script|style)\b[^>]*>[\s\S]*?</\1\s*>', '', s, flags=re.I)
txt = re.sub(r'<[^>]+>', '', body)
for name, pat in claims:          # claims = [(条目名, 审校者引用的片段), ...]
    n = txt.count(pat)
    print('%-16s %s' % (name, ('命中 %d' % n) if n else '** 不存在 **'))
```

- 命中 → 记下**偏移量**，把上下文取出来（`txt[i-120:i+330]`），再判断他说得对不对。
- 不命中 → 他在批评一句你没写过的话，直接指出，不要顺着改。

**⚠ 引文可能落在标题上而不是正文**：四章那份引"配得上，就是一样多"，正文写的是"配得上，就是一样大"——
两处都在，一处是 `h2`、一处是正文段。检索**正文**`txt` 会 0 命中，要用**含标题的全文**再搜一遍，
否则会误判成"错引"。（**稿子内部一处说"一样多"一处说"一样大"本身也值得记一笔。**）

**别用 `<[^>]*>` 切 HTML 标签**：`data-tex="2^n>n"` 的属性值里含 `>`，会提前收尾。用引号感知扫描器：
逐字符走，遇到 `<` 后跟踪引号状态，只有在引号外见到 `>` 才算标签结束。

## 七类病灶（按出现频率排）

| 类 | 症状 | 典型例子 |
|---|---|---|
| **概念混同** | 把两个有联系但不同的概念当一个用 | "连续 = 取极限不会掉出去"（其实是**完备**）；"无限可分 = 完备" |
| **过强断言** | "几乎每一个""任何""最…的一群""不能同时成立""第一条被否掉" | "物理里最基础的量几乎每一个都是极限" |
| **伪引语** | 把现代概括排版成"某某，年份"的落款 | "他发现，'稠密'不足以保证'连续'。——戴德金，1872" |
| **传记因果** | 把"同时发生"写成"因此"——尤其把一场学术争论写成某人疾病/死亡的原因 | "他不是被打倒的——因为他的理论赢了。但他确实是被这场仗耗尽的" |
| **数值误差** | 量级算错 / 绝对误差与相对误差混用 | "误差只有约六百万分之一"（实为绝对误差 6×10⁻⁷） |
| **归属错误** | 把 A 的立场安在 B 头上 | 把"级数解法只是换个说法"的批评归给密尔（密尔恰是主张级数解法的人） |
| **史学框架当事实** | 把后世叙事说成当时人的叫法 | "第一次数学危机"（后世框架，古代材料不足以支持一场"危机"） |
| **构造不闭合** | 定义/构造写出来了，但**按字面读不满足它自己声称的性质** | 戴德金分割"分两堆"把负数同时算进两堆 → "左堆每个数 < 右堆每个数"当场不成立；合格写法：左 = {x<0 或 x²<2}、右 = {x>0 且 x²>2} |

**传记因果单独列一类**，因为它是"文学性最强、最舍不得删"的那一类，也是最容易过界的一类。
判据只有一条：**当代史学共识支持这个因果箭头吗？**（见 §已核事实里的康托尔条：正相反。）

## 第 1 步：独立核证用的权威源

| 主题 | 首选源 |
|---|---|
| 近东/巴比伦泥板（年代、数值、发掘号） | **CDLI**（`cdli.earth`，条目带 Period 字段）、Yale Babylonian Collection |
| 数学家生平与年代 | **MacTutor**（`mathshistory.st-andrews.ac.uk`） |
| **数学家疾病/死因与学术争论的关系** | **Encyclopedia.com 的 Dauben 类词条**（"…were *once blamed* on…, but can now be seen as…"句式最好用）＋ Springer 系综述 PDF（搜 `"were not its cause"` 这类改写） |
| 概念的定义与等价关系 | **Encyclopedia of Mathematics**（`encyclopediaofmath.org`） |
| **某人是否"接话/首次使用某词"** | Encyclopedia of Mathematics 的专题条目（"the word 'set' appears here for the first time"）＋ 哲学期刊里的**带页码原文引用**（Leibniz `A VI.3.158` 转引自 *Mind* 128 (2019): 1135） |
| 实数理论 / 算术化分析的历史 | 学术 PDF 综述（搜 `"Definition and Essence from Aristotle to Kant"` 这类）；Encyclopedia of Mathematics |
| 希腊数学的术语（anthyphairesis 等） | Fowler 以来的史学文献、Encyclopaedia Iranica 相关条目 |
| 悖论的现代解读分歧 | SEP 类条目（Baidu 等二手源只能当线索，不能当依据） |

**核证要点**：区分**绝对误差 / 相对误差**；区分**发表 / 讲义流传**；区分**传统归功 / 可证的史实**；
**维基镜像站（wiki2 / handwiki / wikiwand / owiki 这类）只能当线索**——拿它支撑的改写，采纳前必须补权威落点，
否则记进"待人核"清单，不要落盘。

## 第 2 步：审校人没提的问题，靠"跨章对照测量"挖出来

审校人只盯着**他手上的那一章**，所以**章与章之间的不一致**他天然看不见。而"出版级"恰恰要求这一层。
凡是来件说"这里太长/重复/不对劲"，**先别辩，先量**：

```python
# ① 同栏目在兄弟章里的体量（汉字数）——判断是不是异常值
for f in sorted(glob('第*.html')):
    for cls in ['.trap','.sum','.newint','.strict','.ex']:
        ...  # 按 h2 位置切段更稳，正则找 class 容易串
# ② 各章小标题两两比对，找逐字重名
titles = {章: [h2 文本...]}
# ③ 同栏目内的子标签体例（"其一/其二" vs "陷阱一/陷阱二" vs 无子标签）
```

实测（本项目）：来件说"4.8 与 4.9 内容重复，压缩 15–20%"。
量下来 4.8 = 1134 字，一章 480／二章 558／三章 935 —— **属正常爬升，够不上"重复"**（且 `trapbox`/`sumbox` 是全书体例）⇒ 不采纳。
但同一批测量顺手挖出三处来件没看见的真问题：

1. **子标签体例不齐**：三章 3.8 用"其一/其二/其三"，四章 4.8 改成"陷阱一/二/三/四"——相邻两章同一栏目换了标签法；
2. **两对小标题与邻章逐字相同** ⇒ 目录撞车：`4.1＝3.1`、`4.8＝3.8`；
3. **一个小标题是双向断言而只有一向成立**：`"可数"就是"能被程序列出来"`——停机问题的补集可数却不可枚举。

⇒ **来件的气味对，靶子不对**。这种"气味对、靶子不对"占了不采纳项的一大半，值得在报告里明写。

**顺手还要查来件自身的自洽性**：四章那份第 20 条说"不要再增加知识点了"，而它自己的第 12、13、15 条
走的全是"加一句更严谨的说法"的路子。**用它的原则驳它的建议**，比逐条辩更省事。

## 第 3 步：四组概念的通用拆解口径（可直接抄进稿子）

1. **连续统 ≠ 完备 ≠ 连续函数**
   - 连续统：实数轴作为结构的性质，**精确内容是完备性**。
   - 完备（序完备）：任意非空有上界子集有最小上界；等价于柯西列收敛；等价于戴德金分割处处有数。
   - 函数连续：输入变化足够小 ⇒ 输出变化足够小。
   - **不要让稿子改名叫"完备"**——连续统在历史上就叫 Stetigkeit，是主题词；正确做法是加一段把两义分清。
2. **稠密 ≠ 完备**（三层阶梯）
   稠密：`∀a<b ∃c, a<c<b`。完备：逼近到该有的界限，界限仍在数系内。连续统：把完备有序结构与"没有缺口"的数轴对应起来。
3. **无限可分 ≠ 完备**："分得下去"和"有没有洞"是两件事，前者担保不了后者。
4. **模型结论 ≠ 现实真理**：凡"如果时间只能取有理数…"这类推导，必须写成"**如果坚持在这个模型里**……"。

外加一条：**"洞"这类比喻，首次出现就要先约定**（"存在一个确定的分界位置，却没有任何有理数落在那里"），之后才能放心反复用。

再外加一条：**「有些直觉本身就是错的」不必另立一种错法** —— 在「量程」框架里，一条本身错误的直觉就是**量程为空**（或退化）的那一种。这样全书只保留一种错法（未宣布的推广），却仍能容纳「直觉本身错」的极端情形；免得为一句严谨把书脊从一条改成两条。

## 第 4 步：分三类处理，并**明确报告不采纳的那几条**

- **采纳**：直接改，改完跑回归。
- **修正后采纳**：审校者方向对但方案不行（例：他说"应改成单一年份 1800 BC"，而 CDLI 通行的区间 1800–1600 BC 更稳 →
  保留区间，只补"古巴比伦时期"）。
- **不采纳**：给出理由，并且**指出来源**（例：他推荐的术语我无法核实 → 不引入来源不明的说法）。
- **★ 收紧＋补强，不要弱化**：若审校建议会把**定理降格成修辞**（"唯一一条路"→"这条路"），
  正确做法是"**收紧措辞（全称→限定）＋ 补强依据**"，而不是把话改弱。四章的康托尔条同理：
  来件说"文学性太强，建议删"，正解是**删掉因果断言、保留事实陈述**（信息量不减）。
- **别加字除非同时定预算**：严格化建议几乎都加字，而每章有**规模基线**。
  采纳前先算净增多少汉字，并同时决定"放宽基线 / 从别处等量删"。

千万不要为了显得"认真"而全盘照收——那会把审校者的错误抄进书里。

## 第 5 步：回归断言（这次改完，下次别改回去）

写完修订脚本后，配一个**双向**内容级回归：A 段列"必须消失的过强表述"，B 段列"必须到位的新表述"，C 段查体例。
模板见 `scripts/fact-review-regress.py`。

**两个必须避开的断言陷阱**（实测踩过）：
1. **计数不能直接数纯文本**：`"严格地说"` 在正文 3 处，但注 [1] 里还有 1 处交叉引用，`txt.count()` 会数成 4 而误报。
   要数带标记的版本：`len(re.findall(r'class="lab">严格地说', s))`。
2. **图号别用宽正则**：`图\s*1-\d` 会连"例如图 1-1 的商序列"这种**正文引用**一起抓，顺序检查必然误报。
   只查图题：`re.findall(r'class="fno">图\s*(1-\d)', s)`。

3. **正文、图注、注文要一起查强度**：正文软化了、图注没跟上，是最容易漏的一类。
   实测：正文已改成「有一整类核心概念…用连续模型描述它们时」，图注仍是「物理里那些瞬时量**全都是**…」。
   检查法：把同一话题的**正文句、图注句、注文句各抽一行并排**，只盯强度词（全都／一切／任何／绝对／必然）。

## 坑

- **源稿有多个版本时，先确认哪个是「源头」、转换器是不是整篇重写**。本项目：`工具/构建/html2tex.py` 第 569–570 行
  `open(dst,"w").write(...)` **整篇重写** `排印/正文/*.tex`；而 `\noteref`/`\figref`（自动编号）与注文著录是
  **转换后手工补的**、源 HTML 里没有 → **重跑转换器会把这两类修订一起冲掉**。
  改源之前先跑一次转换器到临时目录做 diff，看清会丢什么。
- **双版（HTML＋LaTeX）项目：正文改动必须两版各改一次**，且用**幂等补丁脚本**（单次原子写＋逐串核对命中数＋
  落盘后回读）。**同一文件不要在同一条消息里发多个 Edit**——它们并行执行互相覆盖，工具却全报 success。
  自检要**比差异不比绝对值**（HTML 里 CSS/JS 花括号天然不平衡、JS 字符串含 `<sub>` 假标签）。
- **`len(str)` 不是字节数**。Python `len(s)` 给字符数，报字节要用 `len(s.encode('utf-8'))`。
  实测把 83463 字节的文件报成 "56607 字节"，差点误判成"图脚本丢了"而做无谓回滚。
- **修订脚本一次写全、逐条断言唯一性**（`if s.count(old) != 1: 报错退出`）。同一批 29 个替换点里
  只要有一个不唯一就整体不落盘，比改一半再查便宜得多。
- 引号统一（中文 `“”`）之后再做内容替换——否则你写的匹配串会因为引号形态不同而全部落空。
