# 分批买入「降本」的三项分解

## 何时用

- 用户问「定投 / 分批 / 网格能不能降成本」；
- 你刚跑完一个「分批 vs 一次性」的回测，准备报「成本低 X%、增股 Y%」；
- 有人（或你上一版报告）写了「定投成本 = 调和平均，恒 ≤ 算术平均价 ⇒ 必然降本」——**这句话是错的**，用本 skill 纠正；
- 要比较两种买入节奏的优劣，或要解释「为什么实测只有 0.2~0.3%，甚至为正」。

## 核心：一个严格分解

设一个窗口内有 `T` 个交易日的价格序列（用你选定的口径，如收盘或 VWAP），
把资金**等额分 N 批**投在等距采样点上（这是「定投 / 分批」的标准实现）。相对
**全窗口算术平均价 `AM`**（= 随机时点一次性买入的期望成本）的成本差为：

```
成本差 = (1 + 采样偏移) × (1 + 调和优势) × (1 + 费率) − 1

采样偏移 = mean(采样点价格) / AM − 1          ← 噪声，可正可负
调和优势 = HM(采样点) / mean(采样点) − 1      ← 恒 ≤ 0；幅度 ≈ 方差/mean²，随波动率增大
费率     = 单边买入费率                        ← 恒 > 0
```

其中 `HM(x) = len(x) / Σ(1/x_i)` 是调和平均。

### 为什么不能省略「采样偏移」

「调和平均 ≤ 算术平均」**只在同一组数内成立**。而定投的 `HM` 是 **N 个采样点**的调和平均，
基准 `AM` 是 **T 个点（全窗口）** 的算术平均 —— **两组不同的数**。
等距采样点的算术平均**不是**全窗口平均的无偏估计：点少时它可以明显偏高。

⇒ **结论必须在波动足够大时才成立**（波动量级 ≫ 采样偏移）；**低波动窗口会被采样偏移翻成正号**。

### 最小实现

```python
import math

def decompose(win, n_batches, fee_buy):
    """win: 价格序列（按时间）；返回三项与合计（均为小数）"""
    T = len(win)
    idx = [round(i * (T - 1) / (n_batches - 1)) for i in range(n_batches)]
    samp = [win[i] for i in sorted(set(idx))]
    am_all = sum(win) / T
    am_s = sum(samp) / len(samp)
    hm_s = len(samp) / sum(1.0 / p for p in samp)
    off = am_s / am_all - 1          # 采样偏移
    adv = hm_s / am_s - 1            # 调和优势（恒 ≤ 0）
    tot = (1 + off) * (1 + adv) * (1 + fee_buy) - 1
    return off, adv, fee_buy, tot
```

> 校验：`tot` 必须与你直接跑「等额 N 批买入」算出的 `成本/AM − 1` **一致到 1e-4**。
> 两路独立算同一个数，是本方法唯一的自检手段。

## 判读规则

| 观察 | 判读 |
|---|---|
| 调和优势的量级 ≈ 0.2~0.3%，采样偏移同量级 | 结论**不稳定**，正负取决于窗口，不能当能力 |
| 波动率大（如 >20%）的窗口 | 调和优势主导，分批**明显降本**（但不代表收益） |
| 波动率小（如 <6%）的窗口 | 采样偏移易压倒，**可能反而更贵** |
| 上涨窗口 / 下跌窗口**符号相同** | 分批的效果**与趋势无关** ⇒ 是真结构效应 |
| 上涨窗口 / 下跌窗口**符号相反** | 测到的是**窗口趋势**，不是规则能力 ⇒ 趋势伪影（常见于「跌买 / 网格」类） |

### 三个必须并列报的基准（换基准即换符号）

1. **vs 全窗口算术均价 `AM`** —— 「不定时随便买」的期望 ⇒ 这才是「降本」口径。
2. **vs 首日全买** —— 「开头一次性买完」⇒ **上行样本里分批必然「减股」**。
3. **同长度随机窗口分位** —— 把同一规则跑遍所有同长度滚动窗口，看事件窗口落在第几分位；
   **50 ≈ 完全随机** ⇒ 锚点**没有额外信息**。

> ★ 实测例（2024-01~2026-09，中芯国际 A+H，n=11）：同一套「等额 12 批」，
> **vs 算术均价 = 增股 +1.1%(A) / +1.6%(H)**，而 **vs 首日全买 = 减股 −1.7%(A) / −3.9%(H)**。
> 两个结论都对，差别只在基准。**报告里只写一个基准 = 误导。**

## 触发型规则的退化诊断（跌买 / 网格 / 回踩类）

**症状**：某「跌 X% 买一批」规则的回测结果在涨/跌窗口**符号相反**。这通常**不是「规则有效」**，
而是**规则根本没触发几次、已退化成「末日全买」**（剩余资金按窗口末日价买入）。
此时它的"优劣"完全由**窗口整体方向**决定——上涨窗口末日价高 ⇒ 显得便宜；下跌窗口 ⇒ 显得贵。

**必做三步**：

1. **报「用档率」**＝实际触发档数 ÷ 设定档数。**< 30% 就该警觉**。
2. **报「全用完需跌幅」**＝档数 × 单档幅度 ÷ 锚点价。在 60~110 天的窗口上，这个数
   若 > 20%，说明该网格**结构上不可能用满**，规则名不副实。
3. **做趋势伪影检验**（同本 skill 的 `dca-cost-decomposition` 分组法）：按窗口涨跌分组看符号。

**实测反例（中芯国际 A+H，2026-09-23）**：把跌买幅度设为**锚点当日振幅 (H−L)** 后，
12 档全用完需跌 **27%~109%**，平均用档率仅 **17%~19%**，1~3 个窗口一档都不触发 ⇒
涨/跌符号相反（A 股 +4.44%／−0.90%；港股 +10.53%／−6.74%）⇒ **趋势伪影，不可用**。
⇒ **「按当日振幅当网格间距」在季度级窗口上不可操作**；要用振幅，必须**除以档数**或**放大窗口**。
（港股无涨跌停 ⇒ 其当日振幅系统性大于 A 股：中位 5.27% vs 3.70%，同一规则在港股网格更宽。）

**反向复算**：触发型规则的**用档数也要独立对撞**，只对撞成本价不够——用档率才决定规则是否已退化。
本项目做法：另写一份不复用主脚本任何函数的实现，逐窗对撞成本价（容差 0.5%，失败 `exit 1`），
并同时打印用档数。

## 持仓级网格回测（跟踪真实股数/现金，而非归一化成本）

前面的分解都是「**把 C 元投出去**」的归一化口径。一旦规则变成**有买有卖的网格**，
必须换成**持仓级回测**：跟踪 `现金 / 持股` 两个状态逐日推进。

**成交模型（先声明，否则结果不可比）**
- **限价单模型**：买档 `当日最低 ≤ 档位价`、卖档 `当日最高 ≥ 档位价` 触发；
  不跳空按**档位价**成交，**跳空按开盘价**成交（买向下跳空更便宜、卖向上跳空更贵）。
- **T+1**：当日买入当日不可卖 ⇒ 日内写死**先卖后买**，就不会再有「先买还是先卖」的歧义。
- **「回归锚点」类档位必须先武装**：锚点价本身就在价格上，若用 `最高 ≥ 锚点价` 判定，
  锚点当日 `最低 < 锚点 ≤ 最高` 会**自己触发自己**。加一条「先出现过 `当日 VWAP < 锚点价`」才武装。

**★ 阶梯权重的「基数二义」（最容易踩）**
用户给的阶梯若权重**恰好合计 10 成**（如 3-2-2-3），说明它是**清仓式阶梯**——
每档应按**同一基准池**的成数卖。若按「每次触发时的当前持仓」算，累计只卖掉
`1 − ∏(1−wᵢ)`（3-2-2-3 → 仅 **68.6%**），**语义完全不同**。
⇒ **两种都跑并写明基准**（实测 A 股差 **+9.7pp**、港股差 **+1.6pp**）。
⚠ **不要用「哪边历史收益高」来选口径**，要按用户语义定。

**★ 同暴露基准原则（最容易被「看起来赚了」骗）**
网格天然**只投入部分现金、长期留一笔未投出**（实测该网格期末**现金占比 42.9% / 47.4%**）。
单边上行样本里留现金多 ⇒ 必然跑输满仓。所以**报收益率没意义**，必须并列报：

| 基准 | 含义 |
|---|---|
| B1 期初全买持有 | 满仓上限 |
| B2 完全不动 | 下限（一笔不交易） |
| B3 等首个信号日才全买 | 隔离「等信号」本身的贡献 |
| B4 按期等额定投 | 同为「分批」的可比对手 |

**实测（中芯 A+H，2024-01~2026-09，n=11）**：网格 A 股 **+81.60%**／港股 **+85.66%**；
vs B1 **−20.84pp / −43.93pp**；vs B2 +61.54pp / +34.83pp；vs B4 +12.25pp / −17.07pp。
⇒ **网格 ＝「部分参与 + 赚波动差价」（自身买均价→卖均价 82.60→90.93 / 51.37→58.71），
收益差主要由「留多少现金」决定，不由规则本身。**

**反向复算要加一条恒等式**：`累计买入 − 累计卖出 == 期末持股`，外加**成交笔数**。
只对撞期末市值不够——中间错一笔也可能碰巧抵消。

## 多起点（vintage）稳健性：单起点结论不可推广

同一套规则、同一段数据的**末端**，只把**起点年份**换掉（起步现金与股票保持一致），
结论可以完全翻转。**实测（同一套网格，3 起点 × 2 市场，期末同一天）**：

| 起点 | A 股 累计 / 年化 | 港股 累计 / 年化 | 网格 − 期初全买（年化） |
|---|---|---|---|
| 2024 起 | +81.60% / +24.60% | +85.66% / +25.62% | −11.21pp / −29.87pp |
| 2025 起 | +48.02% / +25.79% | +62.96% / +33.06% | +7.55pp / −23.11pp |
| 2026 起 | +16.40% / +24.18% | +3.06% / +4.33% | **+32.00pp** / **+22.83pp** |

⇒ **同一套规则在 2024 起跑输满仓、在 2026 起大幅跑赢满仓。**
跑赢/跑输由「起点之后标的怎么走」决定，**不由规则决定**。

三条硬要求：

1. **累计收益率不可跨起点横比**（三者持有期不同：33 / 21 / 9.5 个月）→ 必须给**年化**。
   注意：起点后移时累计收益率会**单调下降**，那是持有期缩短的**机械结果**，不是规则变差。
2. 三个起点 × 两个市场共 **6 格**，实测「跑赢满仓」恰好 **3 格 / 3 格** —— 别只报有利的那半。
3. 结论里必须写明**各起点持有期不同**，否则读者会把「跑得久」误读成「跑得好」。

## 同暴露基准：先把「押了多少钱」这个变量锁住

**症状**：策略期末现金占比 40%~47%，却拿它跟「期初满仓」比收益率。
满仓赢是必然的 —— 不是它方法高明，是**它押的钱多**。反过来市场下跌时，
策略也会因为「押得少」显得抗跌。**两种情况下测到的都是仓位，不是策略。**

**做法（三步）**

1. 算策略的**全程平均股票暴露** `s̄`：

   ```
   s̄ = mean_t( 股票市值_t / 总资产_t )      # 逐交易日算，再取时间平均
   ```

   ⚠ 含**建仓前**的空窗段（那时只有底仓）—— 这是真实暴露，保留，别剔除。

2. **二分求基准的期初建仓比例 `w*`**，使基准的**全程时间平均暴露恰等于 `s̄`**：

   ```
   bench_expo(w) = mean_t( (nav0·w·(1−fee)/p0)·p_t / ( (nav0·w·(1−fee)/p0)·p_t + nav0·(1−w) ) )
   解 bench_expo(w*) = s̄        # 二分 60~100 次足够，精度远超需要
   ```

   ★ **`w*` ≠ `s̄`，绝不能直接拿 `s̄` 当建仓比例**：

   - 标的**上行** → 暴露随价格漂移走高 → `w*` < `s̄`
   - 标的**下行** → 漂移走低 → `w*` > `s̄`

   实测：直接按 `s̄` 建仓会让基准**多承担风险**，把「策略 − 基准」系统性低估约 **4 pp**（年化）。

3. 基准 = 期初建 `w*` 仓（扣买入费）+ 其余留现金，**之后不动**：
   `nav1_bench = sh·p_last + nav0·(1−w*)`

**判读**：`策略 − 同暴露基准` 才是策略**买卖行为本身**的贡献。而 `策略 − 满仓` 可严格分解为

```
策略 − 满仓  =  仓位效应（同暴露基准 − 满仓）  +  交易效应（策略 − 同暴露基准）
```

实测一例：`−11.21 pp  =  −24.53 pp（仓位）  +  +13.31 pp（交易）`（A 股 2024 起，年化）。

**必须同时声明的局限**

- 静态基准只能匹配**平均**暴露，匹配不了**逐日暴露路径**。若策略的暴露是**逆势**的
  （跌加涨减），严格的「逐日同暴露」无法用静态基准复刻（那等于复制策略的仓位路径本身）。
  ⇒ 表比的是「平均承担同样风险」，不是「逐日同风险」。
- 校准后若超额为正，**先问超额来自哪里**：若主要来自「波动收割」（逆势暴露），
  则**单边行情会反转**（单边下行＝一路逆势加仓被套）。别把波动溢价当 alpha。
- 校准**不增加样本**。n 还是那个 n，样本不足的结论仍不成立。


## 陷阱清单（都踩过）

1. **「HM ≤ AM ⇒ 定投一定降本」** —— 错在跨组数。只用这一条推导，会被低波动窗口打脸。
   （实测反例：79 日窗口、波动率 5.14%，采样偏移 +0.964%、调和优势 −0.305% ⇒ **净 +0.683%，分批更贵**。）
2. **只报均值不报中位** —— 强趋势窗口（如 +104%）会主导均值；均值与中位差 4 倍是常态，两个都报。
3. **费率口径不明** —— 港股单边费率约是 A 股的 4 倍（0.108% vs 0.026%），
   它会**直接决定低波动窗口的符号**。引用前先问「用谁的实际费率」。
4. **锚点日期取错** —— 尤其港股：业绩**公布当日晚间**发布，**电话会排在翌日**。
   把电话会日当公布日 → 锚点整体晚 1 天。（核证法见下。）
5. **锚点当日就有前视** —— 公告若为**盘后**发布，锚点当日的收盘/VWAP 属**信息前**价格。
   必须补跑 **T+1 起算**的敏感性；若两种口径方向一致才可下结论。
6. **「90 天间隔」当成常量** —— 按报告期推进时，真实间隔是变动的。
   要同时给「锚点驱动」与「固定天数」两种口径的对照；若两者结论一致，说明对该选择不敏感。
7. **把归一化口径套到网格上** —— 前面几节的「成本 = C ÷ 股数」隐含**资金全投出**；
   网格有留仓，两者不可混用。做网格必须换持仓级回测。
8. **在上升样本里比收益率** —— 网格留现金多，单边上行必输满仓。
   不谈仓位暴露的「网格赚了 X%」是误导：先比同暴露基准，再谈规则优劣。
9. **锚点日的「自己触发自己」** —— 任何以「当日某价」为基准再在其上设档位的规则，
   都要先排除基准日当天因 `最低 < 基准 ≤ 最高` 而立刻触发的伪信号。
10. **★ 残仓容差不对齐（写「独立复算」时的头号坑）** —— 主实现判空仓用 `held <= 1e-9`，
   复算若写成 `sh <= 0`，清仓残留的 **~1e-13 股**会被后者视为「有仓」，
   于是触发一次 **0 股的空卖**，**把该卖档消耗掉**，后续真正该卖的档位全部失效。
   **实测代价：某一组期末总资产差 3.1%**（该期卖出由 2,795.4 股变 0 股）。
   ⇒ 复算的**容差必须与主实现逐字对齐**（空仓 1e-9、买入金额 1e-6）；
   日级对撞里出现 `S0@<价格> × 0.0` 就是本坑的指纹。
11. **守恒恒等式漏项** —— 现金恒等式必须含**卖出费用**：
   `期末现金 == 期初现金 − Σ买入金额 + Σ卖出成交额 − Σ卖出费用`
   （买入费已含在「买入金额」里，卖出费不在「成交额」里）。漏掉时残差恰等于卖出费，
   看起来「差一点」而非明显错，最容易被当成浮点误差略过。
12. **单起点结论当普适** —— 换一个起点年份就换一个答案（见上节「多起点稳健性」）。
13. **把 `s̄` 直接当基准的期初建仓比例** —— 见上节。价格漂移会让基准承担更多风险，
   把策略超额**系统性低估**（实测约 **4 pp 年化**）。必须二分求 `w*`，并以
   `bench_expo(w*) == s̄` 作自检。
14. **分批建仓基准的现金初值算错** —— 若基准是「N 日等额建仓」，现金要从 **`nav0`** 起逐批扣减。
   写成 `nav0·(1−w)` 起扣，N 批之后会变成 `nav0·(1−2w)`（甚至为负），
   结果**离群且看起来"很有信息量"**（实测把某格超额从 +27 pp 抬到 +64 pp）。
   自检：建仓完成后剩余现金应恰为 `nav0·(1−w)`。


### 附：公告日期怎么核证（A+H 场景）

- **A 股**：东财 `RPT_FCI_PERFORMANCEE`（业绩快报，字段 `NOTICE_DATE`）、
  `RPT_LICO_FN_CPD`（定期报告披露日）、`RPT_PUBLIC_BS_APPOIN`（预约披露，含 `ACTUAL_PUBLISH_DATE`）。
- **港股**：**港交所披露易原文 URL 自带日期** ——
  `hkexnews.hk/listedco/listconews/sehk/<年>/<月日>/<编号>_c.pdf`，
  路径里的 `<年>/<月日>` 就是**发布日**，比任何二手表都硬。
- **第三源**：万得公告库的 `date` 字段 + 公告**内文日期戳**（「中國上海 ─ 2025年8月7日 ─ …於今日公佈」）；
  公司官网新闻；媒体（看是否写「**X 月 X 日晚间公布**」）。
- **判据**：若「公告日 = 电话会日 − 1」在多个报告期稳定成立，说明该市场是**盘后发布、翌日开会**的节奏。

15. **「累计买入额」被当成净投入** —— 网格/循环策略里卖出回款又回补现金继续买，
    「累计买入支出」= 期初现金 × **周转倍数**（实测 **1.33×~5.37×**）。
    报「投了多少钱」必须用**净投入（期初现金 + 种子股）**；累计发生额只能用来算**周转倍数**
    与**已实现率**（已实现 ÷ 累计买入支出）。直接把累计额当本金会**高估收益率数倍**。
16. **分解恒等式验不了成本法** —— `总盈亏 = ①种子浮盈 + ②已实现 + ③未实现` 中，
    成本项在 ②③ 之间**相消**（②+③ 恒等于「现金净流入 + 期末市值」），
    所以该恒等式**只能验「分解是否完整」，验不了成本法本身**。
    要验成本法，须**从流水独立重算**（不引用内部状态），并以 **FIFO** 作第二重口径对照
    —— 两种口径的 **②+③ 之和应相同**（变的只是实现的早晚）。
17. **回测用「浮点股数」，现实中下不了单** —— 归一化成本口径（C ÷ 股数）可以不算手数，
    但只要回测**跟踪真实持仓/现金**，就必须加**手数约束**：**最低成交量 + 整手步长**。
    ⚠ **两者不是一回事，且各市场不同**：
    A 股步长 **100 股**（「不低于 200 股」是规则约束，不是交易所约束）；
    **港股按「手」交易，中芯国际每手 500 股** —— 若误用「100 的倍数」，
    会凭空造出一个**不存在的碎股市场**，结果偏乐观。
    报成效时**必须声明这两项**。
18. **手数约束的差异不来自「取整」本身** —— 单笔取整的缩水极小（实测均值 134 股、最大 467 股，
    全部不足 1 手），差异来自两条**下游后果**：
    ① **档位作废**（某档算出 < 最低量 ⇒ 该档作废；实测 6 组共 15 档）。
       这部分可用**零股/碎股兜底**（小池一次性清掉）**回收**；
    ② **级联**（卖出少 ⇒ 回款少 ⇒ **下期买入预算变小**，因预算＝期初现金 × 比例）
       这部分**不可回收**，且**符号不定**（实测 −2.42 ~ +0.16 pp）。
    ⇒ **正确的做法**是把总差**分解**为「卡档效应 ＝ flush 兜底 − 主口径」＋
    「取整路径效应 ＝ flush 兜底 − 无约束」，**不要笼统归因为「取整」**。
    另：**取整会留残仓**（四档各自向下取整后不再清零），残仓使下期基准池变小，
    进而让更多档位落进「不足最低量」—— 理论上有**自强化死锁**，
    但每期新买入通常会把池子重新做大，**实测未形成连续死锁**。

19. **「锚点价 / 参考价何时可用」必须写明，并把「加约束前后是否改变结果」当成一个结论来实证**
    —— 用**当日 VWAP**、当日收盘价或当日振幅当锚点时，这些量都是**当日全天信息**（收盘后才算得出）；
    若规则允许它**当日就成交**，就是**前视偏差**。正确做法是**锚点日不成交、自次一交易日挂单**。
    ★ 但要预期一个反直觉结果：**这条约束常常不改变任何数字** ——
    因为档位价是由**同一天的**锚点价与幅度生成的，而锚点价必落在当日 `[最低, 最高]` 内，
    于是「买 −1 档」触发需 `v0 ≥ 当日最高价`、「卖 +1 档」需 `v0 ≤ 当日最低价`，
    两者只有「全天成交都在同一价位」时才成立 ⇒ **锚点日结构性地触发不了任何档位**。
    ⇒ 所以：① 该约束的价值是**把隐含假设变成明写规则**（防日后规则/数据变化引入前视），
      **不是**「能提升回测收益」；② 落地必须**实证**（扫描 `v0` 在当日区间中的相对位置、
      统计锚点日成交笔数、对比加约束前后的**逐项差**），**不能只写一句「已按 T+1 处理」**；
    ③ 报告里必须**给出参考价（锚点价）列 + 首个可交易日**，让读者能自行核对时点；
    ④ 「首个可交易日」要按**交易日历**推，不是当日 +1 自然日（停牌日会被计入）。

## 输出模板

```
【前提】窗口 = ...，锚点 = ...，价格口径 = ...（VWAP / 收盘），费率 = ...
【主表】逐窗口：区间收益 / 波动率 / 各规则成本 / 相对 AM / 相对首日全买
【分解】逐窗口：采样偏移 / 调和优势 / 费率 / 合计   （合计须与主表一致）
【分组】按窗口涨跌分组，看符号是否一致（判趋势伪影）
【对照】同长度随机窗口分位（判锚点有无额外信息）
【敏感性】T+1 起算 / 固定天数窗口
【手数】最低成交量 + 整手步长（A 股 100/200 股；港股按手，如 500 股）；取整方向（向下/凑一手）；不足最低量的处理（作废/兜底）；零股·碎股兜底对照
【时点】参考价（锚点/基准价）何时可用 + 首个可交易日（按交易日历）；加时点约束**前后逐项差**（证明是否改变结果）
【稳健性】换 3 个起点年份 + 年化（消除持有期差异）；列出跑赢/跑输满仓的格子与名单
【结论】带证据等级 + 样本量警示（n<20 一律标样本不足，不得据以选规则或仓位）
```

20. **报告表格必须明写「期初持股 / 期初现金」，且列间口径不对称时恒等式必须实测。**
   2026-09-23 实例（中芯国际业绩锚点网格轮）：用户要求「补充期初持股和期初现金」→ 补列过程中
   **暴露两处隐性口径问题**：
   ① **同一份报告内「持股」列有两种口径**（§二 含锁定种子股 5,400 股、§五/§六 不含 4,400 股，
      **都没标注**）⇒ 统一为「账户总持股 ＝ 锁定种子股 ＋ 网格持仓」；
      ★ 注意**跨版本引用时两版数字相差恒定为种子股数**（A 1,000 / H 5,000 股），必须写明版本。
   ② **首版表注的现金恒等式是错的** —— `期初 ＋ 卖出所得 − 买入花费 − 费用` **不成立**，
      实测逐期差**恰等于当期买入费**：因「**买入花费**」列**已含买入费**而「**卖出所得**」是**毛额**；
      正解 `期末 ＝ 期初 − 买入花费(含费) ＋ 卖出所得(毛) − 卖出费`（`卖出费 ＝ 费用 − 买入费`）。
   **通用做法**：① 任何「账户状态表」都要有**期初持股/期初现金**，并写明持股是否含锁仓部分；
   ② 同一报告内同名含义的列**口径必须一致**，不一致就统一并记账差异来源；
   ③ 写恒等式**前**先写一个**数值探针**把候选式逐期实测（本次：候选 A 全期失败、候选 B 全期成立），
      把赢的连同**不对称提示**写进表注；
   ④ 验证时**直接把报告 MD 原文当输入解析**（本次新增「报告文本层」校验 194 项），
      **不要只信生成脚本的自检**（脚本自检通过 ≠ 报告文本自洽）。

21. **★ 「独立复算」必须做到「逐笔」级，且要接受「复算自己也可能错」**
   2026-09-23 实例（中芯国际 24 期全样本轮）：样本从 11 期扩到 24 期后跑独立复算，结果
   `ntrade` **96 vs 内核 95**、期末现金差 **444.88 元**（≈0.05%）。
   → 若只比**期末总额**，这个差会被当成浮点误差放过；**必须逐笔对撞**才发现，是复算在
   **买入分支漏检**「取整后不足最低量（A 200 / H 500）⇒ 该档放弃」——多出 1 笔 100 股买入。
   → 修正后**逐笔 0 不一致**。**方向是「内核对、复算错」**，不是内核错。
   **通用做法**：① 写一个**独立的逐笔对撞脚本**（把两版成交流水按 `(期, 日, 档位, 股数)` 并排打印，差异行打标记）；
   **先对齐笔数再逐笔比**——只要有一笔多/少，后面全部错位，**「错位」本身不是错误，第一处错位才是**。
   ② 对撞前先确认两版读的是**同一份数据**（本次复算一开始用了自己的 `rows` 结构、键名不同直接 `KeyError`
   —— 这类错**必须当错误修**，不要为了让脚本跑通而改容差）。
   ③ 最后跑「**回归复现**」：用独立实现去复现**在役版本**的历史数字（本次 V2024/25/26 × 2 市场 × 8 字段 = **48/48**），
   才能同时证明「新样本没污染在役口径」与「复算实现是对的」。
   ④ 心理上要接受：**反向复算的第一价值往往是抓出复算自己的 bug**，不是抓出主实现的 bug。

22. **★ 「零缺口」的判据要选对（否则大量假报缺数据）；扩样本前先自证「没污染在役口径」**
   · **零缺口 ≠ 相邻交易日间隔 ≤ N 天** —— A 股春节/国庆天然 5~11 天、港股遇台风/黑色暴雨会**全日停市**
     （实测 2023-07-17 泰利 / 2023-09-01 苏拉 / 2023-09-08 黑色暴雨）。按间隔判 ⇒ **A 25 处 / H 14 处全部假报**。
     真判据 = **「合并文件的交易日集合 == 独立第二源（剔除其占位行后）的集合」**（对称差两边都须为空）。
   · **扩样本（换起点、拉长 N）必须先自证没污染在役口径**：把样本从「铁律起点」前推，会**与时间口径铁律直接冲突**。
     处理 = **用户明示 ＋ 物理隔离（独立目录/独立模块/不改在役文件）＋ 与在役段存在可机器对撞的重叠区**，
     重叠区**必须逐值对撞**（本次 **66/66 ＋ 48/48**）。
     ★ 并要在台账写明**它不构成对既有 ⛔ 结论的翻案**（同项目另有一条 ⛔「样本从 5 年拉到 22 年：与铁律冲突，已废止」
     —— 方向相同但性质不同），否则日后必被误读成「既然能拉到 2020，那 22 年也能拉」。
   · **扩样本会改 N、通常不改定性结论**：本次 11→24 期后「网格跑输满仓**主要是仓位效应**」仍成立
     （同暴露校准后 A **+4.85 pp** / H **+0.13 pp**）；14 格里 vs 期初全买 **4 正 10 负**、
     正格**全部集中在最短的两个起点**（N≤7）⇒ 再次印证「**起点年份本身决定结论**」。

23. **★ 「账户状态」要逐期展开到「各起点」；三条恒等式要「生成器断言 ＋ 独立腿复算」双背书 —— 并防三类自欺**
   2026-09-23 实例（用户先后说「补充期初持股和期初现金」「增加各种情况下的现金使用变化，持股的变化」，
   并选定切法＝**各起点的逐期明细**）：
   · **列要成链**：光给「期初持股 / 期初现金 / 期末现金」不够 —— 必须同时给
     **本期买入(股) / 买入花费(含费) / 本期卖出(股) / 卖出所得(毛额) / 卖出费 / 期末持股(总)**，
     否则读者无法逐行自核。再加两列**净变动**（**持股净变动 ＝ 买−卖**、**现金净变动 ＝ 期末−期初**），
     一眼看出「现金被用掉多少、持仓堆了多少」。
   · **★★ 三条恒等式，且「卖出费」必须自算**：
     ① 期初持股 ＋ 买入 − 卖出 ＝ 期末持股；
     ② 期末现金 ＝ 期初现金 − **买入花费(含费)** ＋ **卖出所得(毛额)** − **卖出费**；
     ③ 本期期初 ＝ 上期期末（首期 ＝ 种子股／起点现金）。
     ⚠ 典型内核字段是「`p_buy_amt` **已含买入费**、`p_sell_amt` 为**毛额**」⇒ **卖出费不在字段里**，
     必须**从成交流水按买卖方向独立聚合**（本次即如此，顺带完成「买入额/卖出额/费用」三项对账）。
     **若直接写 `期末 ＝ 期初 − 买入花费 ＋ 卖出所得 − 费用`，会重复扣一次买入费**（第 20 条踩过）。
   · **三类自欺，逐条自查**：
     ⓐ **预设结论套数据**：本次初版读数提示写「跌时加仓、涨时减仓」，实测 **14/14 全是净增持、
       0 格净减持** ⇒ 预设与数据直接矛盾。**订正方式不是改措辞，是整段删除**，
       改为**只报可观测量**，并明写「由本表判不出 X 的条件，须另做敏感性」。
       ⇒ **凡自动生成的解读句，其形容词必须由数据分支决定，不能写死**。
     ⓑ **手写区间随样本失真**：结论里手写「A 股现金占比 32.8%~37.4%」，真值 **32.8%~35.4%**
       （37.4% 实为**港股**某起点值被误当 A 股上界）。⇒ **凡「随样本变动的区间/极值/符号统计」
       一律生成器现算**；本次同错**同时存在于报告、审计台账、否定结论专题三处** ⇒
       **订正要全库检索同一数字**，不能只改报告。
     ⓒ **方向单一的样本不能推机制**：14 格方向全同（都净增）时，
       **判不出「转向」的条件** —— 只能报事实，机制留待敏感性实验。
   · **验证要求**：新增列必须进**独立复算腿**。本次在独立脚本里**自建逐期金额/费用累加器**，
     推出期初状态与两个净变动，与引擎产物 **24 期 × 11 字段 × 2 市场 ＝ 528 值逐值对撞（0 不一致）**，
     并让独立腿**自己**校验三条恒等式（0 处）。⇒ **「新列只在生成器里有」不算验证过。**

24. **★ 加列 / 改表这类「小改动」，真正的风控是「机器自检 ＋ 负向测试」**
   2026-09-23 实例（中芯国际 24 期全样本轮，用户：「增加报告期股价最高和最低价列以及跟锚点价的百分比」）：
   · **加列最常见的静默损坏是「分隔行没跟着改」** —— Markdown 表头写了 19 列、分隔行还是 15 个 `|`，
     渲染出来列会错位，但**生成器不会报错、报告照出**。
     → 治法：**落盘前逐表核对「表头 / 分隔行 / 每一数据行」列数一致**，不一致 `assert` 中止。
     本轮 **30 张表全过**。
   · **但「加了自检」不等于「自检有效」** —— 任何永远绿的检查都是**假门禁**。
     → 必须做**负向测试**：故意破坏一处（本次把分隔行少写 1 列），确认 ① 退出码非 0、
     ② 抛出预期异常、③ **产物未被改写**（本次三条全中）。
     同理，数值对撞也要证明**非平凡**：把窗口边界故意移动 1 天，极值应发生变化
     （本次窗口右移 → **6/24 期**变化、去掉末日 → **2/24 期**变化）。若怎么动都不变，说明对撞是空的。
   · **报告里写「与 X 无关」这类断言，必须机器化** —— 本次 §5.3 声称「期内最高/最低与起点无关」，
     就在生成器里按 (市场, 报告期) 建索引、跨 7 个起点**逐值对撞**（**156 组 0 不一致**）。
     口述的「无关」半年后会被当成「不同情形」重新讨论一遍；对撞过的「无关」才是结论。
   · **新量优先放「唯一出现处」，不要复制到 N 张表** —— 该量与起点无关 ⇒ 只在 §5.1/§5.2 列一次，
     §5.3 的 7 组表写清「不重复」及理由，避免同一数字出现 7 次被误读。
   · **路径统计 ≠ 可交易信号**：新增列给出的是「期内最高/最低相对锚点价」这类**路径**统计。
     「买档价在期内被打到过」（本次下探 ≥1 档 **22/24 期**）**不等于实际成交** ——
     成交还受「锚点日不出手 / T+1 日内先卖后买 / 期初池锁定 / 整手取整后不足最低量即弃档」约束。
     凡报这类数，必须同时写清「它说明了什么、不说明什么」。

25. **★「未卖出即沉淀为种子股」被当成提高胜率的技巧** —— 这是**提仓位**的规则，不是提胜率的。
   实测（24 期、2020Q3 起、单标的）：期末现金占比 **34.1% → 1.5%**（A）/ **45.6% → 0.5%**（H），
   成交笔数 **95 → 9** / **90 → 15**，年化 **+7.97% → +12.43%** / **+8.33% → +17.32%** —— 看着全面变好，
   但 14 个「起点×市场」格里 **跑赢 9 / 跑输 5**（年化差 **−9.04 ~ +26.70 pp**）：**上涨段跑赢、回落段跑输**。
   机制：沉淀掉「退出通道」⇒ **期末网格持仓恒为 0**（无可卖池）⇒ 下期只有「本期新买的」能卖，
   而买入预算来自现金、现金被逐期买光 ⇒ **规则必然退化成「分期满仓 ＋ 静态持有」**
   （本样本最长连续零成交段：A 18 期 / H 20 期）。⇒ 它把「网格」变成「分期满仓」，**放大的是股票暴露**。
   ⚠ 且**单一标量 s̄ 匹配不了逐日暴露路径**：本策略暴露**爬坡**（~50%→~100%）、基准**恒定** ⇒
   同暴露差（A +7.17 pp / H +5.19 pp）只能读成「本样本这段行情里爬坡式暴露优于恒定暴露」，**不可外推**。
   ⚠ 规则原话常有歧义（「当期没有触发卖出条件」＝按**股**还是按**期**？）：两读法只 **4/14 格**相同
   ⇒ **口径必须先定死并登记**，否则同一句话能算出两套结论。
26. **★ 报告引用「外部产物」却只用时间戳判新旧** —— 「独立复算 N 项全通过 / 未通过」这类段落
   常常是**从外部 JSON 读入**的。若先出报告、后修复算，报告就会嵌进**上一轮**的结论。
   **实测代价**：报告写「未通过 17 项」，而实际复算 JSON 已**全绿** —— 只因**同一分钟内先出报告、后出复算**。
   ⇒ 做法：外部产物落盘时写入**内容指纹**（它所依据的源文件 md5），报告生成前**比对指纹**，
   不一致即 **`raise` 中止且不落盘**（断言必须放在落盘之前）；并**用负向测试证明闸门会红**
   （篡改指纹 / 改源一个字节 ⇒ 两条路径都红且报告哈希未变）。⚠ 有意副作用：改动计算相关源后
   **必须重跑复算**才能重生成报告 —— 这正是想要的纪律。**时间戳判新旧不可靠，比内容指纹。**
27. **★ 有负向测试的门禁**仍然可能是瞎的 —— **对撞面必须跟着「敏感点在哪」走**
   2026-09-24 实例（第十五轮，种子股止盈 +50% 减半 / +95% 清仓）：
   · 新增的「止盈总量对撞」只覆盖 **V2020 两格**；而同轮修掉的缺陷「**T2 档放弃未锁存**」
     （缺锁存 ⇒ 价格停在 +95% 以上且该批不足一手时**逐日重复计数**）
     在 14 个「起点×市场」格里**只有 V2023_A 敏感**（锁存 **6** ／ 去锁存 **469**）
     ⇒ 该门禁**结构性抓不到这个缺陷**，第一版负向测试**报绿、实为空洞**。
   · 陷阱 24 说「加了自检不等于自检有效，要做负向测试」，但**这条只保证「你试的那个缺陷」能被逮住** ——
     若缺陷落在**对撞面之外**，负向测试照样绿。**两件事必须同时做**。
   ⇒ 治法三条，缺一不可：
     ⓐ **对撞面跟着敏感点走**（本次由 2 格扩到 **14 格 × 8 字段**）；
     ⓑ **把敏感性写进检查本身**：取「该机制最敏感的那一格」，把该机制关掉，
        被检量必须**显著变化**（本次 **6 → 469**）；不变 ⇒ 该检查视为空洞（自证门禁有效）；
     ⓒ **负向测试双向**：① 被检侧去掉该机制 ② 产物侧注入缺陷值 —— **两侧都必须 `rc≠0`**
        （单向只证明一半）。
   · **伴生坑：缺陷可能「不影响净值、只污染统计量」。** 本次重复计数**一分钱都不影响**（不产生成交），
     只把「放弃档数」虚增 100 倍。⇒ **只对撞终值/净值的门禁天然抓不到它**，
     必须对撞**计数量**（次数、笔数、档数）。
   · **通用教训**：**「检查通过」≠「检查有效」**，且**「负向测试通过」也不等于覆盖完整**。
     新增门禁后先**实测敏感度分布**（到底哪一格、哪个量在动），再据此定对撞面；
     并让门禁**自己证明自己会红**（把敏感性做成一条常驻检查，而不是写在注释里的口头承诺）。
28. **★ 回撤（MDD）指标不能用「同比缩放」做负向测试（会假绿）** —— 2026-09-24 实例（第十六轮，「回撤最小 × 年化>20%」）：
   · **算 MDD 必须重建逐日曲线**：只看期末净值会漏掉期内峰谷（本轮回撤全落在 2021-08→2022-10 的下行段）。
   · **★ 篡改要改「形状」，不能等比缩放**：把整条资产曲线 ×0.99，**峰值与谷值同比 ⇒ MDD 不变**，
     于是「篡改版」与「原版」的 MDD 一样，负向测试**报绿**（NT-DD-1 第一版正踩此坑）。
     有效做法：① 引擎侧**直接把 MDD 值改掉**；② 只把曲线**前 1/3 段 ×1.20**（改变形态）—— 两条都必须让对撞变红。
   · **另一个静默缺陷源：导入顺序**。`L.MARKETS` 在**导入时**就绑定了 `G.A` 的**对象引用**；
     若「注入行情」的 `install()` 在 `import` **之后**调用，引擎会算出错值（实测偏差达 **71%**）。
     ⇒ 凡「注入 → 导入」链路，**install 必须早于 import**；这条错值运行本身就是「闸门会红」的实证。
   · **★ 判「参数更优」前先做排名一致性**：单起点最优一律先按**过拟合**嫌疑处理 ——
     本次 H 股最优 `boff` 是**尖峰**（0.5→0.6 掉 1.91pp），跨起点 Spearman ρ 仅 **+0.244**，最优方向**随起点翻转**。
29. **★ 判「变量更优」必须先看「跨起点同号数」；且「尖峰/平台」是配置相关的** —— 2026-09-24 实例（第十七轮，年化变量规律性总结）：
   · **单起点 / 单组合的「最优」几乎全是拟合噪声**。做法：把每个候选取值在 **7 起点 × 2 市场 = 14 格**上各跑一遍，
     只看**符号一致性**：同号 ≥12 = 真规律；9~11 = 条件规律；≤8 = 伪规律。
     （本轮：α 单调 14/14、买入前重 13/14 = 真；止盈 0.20/0.40 = 7/6、0.15/0.30 = 7/7 = 伪。）
   · **★★ 陷阱 28 的措辞要收窄**：陷阱 28 写「H 股最优 `boff` 是尖峰（0.5→0.6 掉 1.91pp）」——
     那是**在一个特定组合内部**测到的**局部敏感性**。同一变量放到 14 格聚合口径下，**0.5 / 0.6 / 0.75 是平台**
     （13/14 同号，均值 +5.5 ~ +7.7pp）。⇒ **「尖峰/平台」的判定本身依赖参考配置**，
     不可把单组合的局部敏感性当作该变量的固有属性；判稳健性必须**多配置 × 多起点**。
   · **★ 变量间有交互，OFAT 结论不可直接叠加**：`boff` **深档**的符号随止盈档**翻转**
     （tp(0.50,0.95) 下 +2.38pp、tp(0.30,0.60) 下 −1.22pp）⇒ 多参数优化必须**整组检验**，不能逐维最优再拼。
   · **参考配置要取「用户原始口径」**，别拿「上一轮拟合出的改进」当基准 —— 否则测到的是「离最优点多远」，不是变量本身的效应。
   · **给独立腿加能力（如 `participate`）时，零漂移必须实测**：用**改动前脚本**重跑并**逐键对撞**，
     不能只靠「默认值不变 ⇒ 应当零漂移」的口头论证。（本轮实测：三口径 JSON 差异键「无」、55/65/118 全绿。）
   · **负向测试要挑「起点/分组」这类静默缺陷**：本轮「忽略起点（t0 恒取首日）」⇒ 26/38（恰好 12 个多起点格失配），
     证明闸门对这类缺陷敏感 —— 只篡改净值（×1.05）会得到 0/38（全红），但抓不到「分组维度漏检」。

30. **★ 「在参数网格里挑最大值」不是「事前承诺」，哪怕事后声明「不再改」** —— 2026-09-24 实例（第十八轮，用户 144 组结论核对）：
   · **先挑格子、再命名「最优组合（一旦确立不再改）」，顺序是反的**。挑最大值那一步就是**事后选择**
     （post-hoc selection）——它使后续的「不再改」失去意义，因为你已经用全样本挑了赢家。
   · **识别特征：响应面是「尖峰地形」**。本轮实例：A 股止盈族 `tp=(s,2s)` 在 s=0.25→0.30→0.35
     上是 17.36%→**18.58%**→14.65%（**一个台阶掉 3.93pp**）；港股 s=1.00→1.20→1.50 是
     18.80%→**20.12%**→17.50% ⇒ 用户选中的 s=1.00 **并不是峰值**。
     **只要「最优」随网格平移，就说明它在拟合噪声。**
   · **正确的事前承诺三步**：① 先声明判据＝**跨起点符号一致性**（不看单起点绝对值）；
     ② 只接受 ≥6/7（或 ≥12/14）同向者为候选；③ 候选写成**区间**（如 +25%~+35%）而非点，避免再次 argmax。
   · **单起点网格里的「区间窄」是假象**：本轮用户表每档只有 2~4pp 区间，那只是因为区间只在
     `seed × c0` 两维上取；**换到跨起点维度，同档位的年化会散开十几到几十 pp**
     （本轮 A 股 19.65%~36.40%、港股 −4.16%~41.90%）。报「预期年化 X%」必须说明这个 X 是
     哪个起点、哪个网格角，否则是误导。
   · **必须做分量拆解才知道改善由谁承载**：本轮「止盈 + seed」组合在 A 股 6/7、港股 5/7 看似可行，
     但拆开后港股 seed 分量**年化 2/5（最多 −5.22pp）**、止盈分量**回撤 0 改善 / 2 变差** ⇒
     **组合的「5/7」是两个弱分量凑出来的假象**。**任何「组合有效」都要拆成单分量各自的一致性。**

31. **★ 「最优」不是一个「跑得更全」就能回答的问题——先给判据，再量噪声带** —— 2026-09-24 实例（第十九轮，止盈档 × 卖出档 121 组全量网格）：
   · **用户的问法是「这个标准是最优吗，全量跑一遍」。但「全量」不等于「有答案」**：只要判据没写死，
     跑 121 组再取最大，就是**更大规模的事后选择**（陷阱 30 的放大版）。做法：先把判据写死成
     **P1 样本内最大化 ／ P2 目标式（年化>20% 下回撤最浅）／ P3 跨起点一致性 ≥12/14 ／
     P4 邻域平台 vs 尖峰 ／ P5 Pareto 支配**，再跑。**判据必须跑之前写，不能看到结果再挑。**
   · **★ 先量「噪声带」，再谈「差距」**：算**相邻档位的平均/最大步长**（本轮 A 股卖出档方向
     平均 0.19pp、最大 0.88pp；止盈档方向平均 1.55pp、最大 5.58pp），把它与**候选之间的差距**比。
     本轮「用户方案 vs 网格最大值」差距 **0.88pp**，与相邻档最大步长**同量级** ⇒
     **必须直接宣告「最优不可判别」**，而不是报一个「最佳组合」。
     **不做这一步，就是在噪声里挑冠军。**
   · **多参数改动必须拆成单维逐一看**：用户给的是「止盈档 + 卖出档」**两维组合**，只报一个结论
     会掩盖「一半成立、一半不成立」。做法：**固定其中一维的每一个取值**，看另一维的候选是否**每次都赢**
     ——本轮固定 11 个卖出档，+30/+60 在 **11/11** 下都优于两侧 ⇒ 真山脊（不是挑格子）。
   · **★ 支配关系（Pareto）比排名更有杀伤力**：排名只说「不够好」，**严格支配**说的是
     「**存在一个更好的，且不付代价**」。本轮 A 股有 6 组、H 股有 28 组严格支配用户方案；
     A 那 6 组全是「同止盈档 + 更高卖出档、回撤一分不变、年化更高」⇒ 该改动直接被降级为「次优」。
   · **★ 「窄脊」不是「平台」，不能写成单点最优**：本轮止盈档边际 …17.40% → **19.40%（+30/+60）** → 14.58%，
     **上调一档 −4.8pp、下调一档 −1.4pp**。这类变量只能写成**区间**（如「+25%~+30% / +50%~+60%」）。
   · **★ 判「某变量是不是回撤工具」用「行内 vs 行间」看**：固定止盈档看**行内**回撤极差
     （A 仅 0.46~1.02pp），对比止盈档**行间**台阶（15pp）⇒ **止盈档是回撤杠杆，卖出档不是**。
     不要凭「它改了卖出价」这类直觉下判断。
   · **★「回撤指标」的另一个坑**：同一止盈档下，卖出档只要没把档位压进回撤窗口，回撤**一分不变**
     （本轮 A 股六组支配者回撤全等 −38.47%）。**「回撤没变」不等于「没影响」——它可能只是没被触发。**
   · **验证要求（本轮已做）**：**全网格非抽样**独立复算（1694/1694，Δ净值 0.000000%）＋
     负向测试 5 个用例（改数值 → 0/48、忽略参数 → 0~4/48、恢复 → 48/48）。
     **「全量跑」很便宜（1694 次仅数秒），所以没有理由只抽样验证。**

32. **★ 「给出更优方案」是一个判据问题，不是一个搜索问题 —— 而且一致性判据必须成对。**
    - **症状一：把「在某一个起点上更大」当成「更优」。** 支配关系的正确定义是
      **年化不低于、回撤不深于、至少一项严格更好**；单看年化会把「用回撤换来的年化」也算成更优。
      实例：`+25/+50 × 浅中(.75,1.75,2.75) × 0.3×` 一族 **Δ年化 14/14 全为正**（看着最稳），
      但 **Δ回撤最差 −11.47pp** —— 一致性满分却完全不可采纳。
    - **症状二：只报样本内支配，不报跨起点一致性。** 实例：`+100/+200 × 低(-0.5,0.5,2,4)`
      在参照上确实支配，但跨 14 格 **Δ年化只有 6/14** ⇒ 纯拟合。
      ⇒ **成对使用**：`Δ年化 ≥0 的格数` **与** `Δ回撤最差值` **必须同时报**（本项目的 D2a / D2b）。
    - **症状三：用「行平均边际」支持或否定一个维度改动。** 当行与行方向相反时，
      行平均会给出与**每一行都相反**（或弱到不可判）的结论。
      实例：以「对 11 个止盈档取平均」的卖出档边际判定 (0,2,4,6) 是「唯一凹陷」并推荐「维持 (0,1,3,5)」；
      按行看，+30/+60 那一行的 A 年化其实从 18.58% 一路升到 20.33%。
      ⇒ **凡用边际做结论，必须先声明是「分行」还是「行平均」；能分行就分行。**
    - **症状四：在网格上取 argmax 并称之为「最优组合」。** 当相邻档落差（平均 0.29pp、最大 0.88pp）
      与「推荐 vs 参照」的差距（0.88pp）**同量级**时，argmax 落在噪声里
      ⇒ 结论只能写成**区间**（本例：卖出档 `0/3/5/7 ~ 0/4/8/12`，该带 A 年化 19.85~20.33%，幅度仅 0.48pp）。
    - **症状五（治理）**：报告定稿前必须做**逐块表列数自检**。方案 key 常自带 `|`
      （如 `+30%/+60% | 高跳 0/4/6/8 | 原(1,3,5) | 1.0x`），直接塞进 Markdown 表格单元格会**静默拆列**。
      只检查「竖线数 ≥3」抓不到，必须**按连续表块比对列数是否一致**。

33. **★ 负向测试的篡改必须「自证有效」；A/B 对照的差异必须归因到「是否被触发」** —— 2026-09-24 实例（第二十一轮，R-01 vs 对照卖出档全量 A/B，14 格 × 2 组）：
   · **症状：形状篡改打在不敏感位置 ⇒ 假绿。** 把复算曲线 **45% 位置**（非谷底）某日 NAV ×0.98，
     既没改变回撤（谷底没动）、也没改变末点（年化没动）⇒「错版复算」与内核记录**逐位相同**
     ⇒ 脚本报「未检出」。**这不是比对失灵，是篡改本身无效（vacuous）。**
     做法：篡改必须打在**敏感位**（本例＝原谷底），并在用例内部**先断言「篡改确实改变了目标量」**
     （`abs(mdd_after) > abs(mdd_before)`），否则直接判**测试失效**，而不是判「通过」。
     ⚠ 与陷阱 28 的「等比缩放不改 MDD」是**两种不同的假绿**：那条是**形状**问题，这条是**位置**问题。
     **凡是「负向测试全绿」的结论，都要问一句：篡改真的动到了目标量吗？**
   · **A/B 对照的差异归因三步法（可复用）**：
     ① **比峰谷日期**：本轮 14/14 格峰谷**完全相同** ⇒ 差异不是「回撤时点结构」变了，而是
        「从多高的位置跌下来」变了（差别在回撤**之外**累积）；
     ② **比回撤区间内的行为**：A 股该段两组卖出/止盈**逐格相同** ⇒ 净值路径一致 ⇒ **回撤逐位相同**；
     ③ **若区间内行为不同，沿链条往前追**：H 股区间内止盈分岔（甲 500 股 vs 乙 0），源头是区间**之前**
        最早一期的沉淀股数差（甲 4,000 / 乙 3,000）经「沉淀股数 → 成本台账 → 止盈触发」传导而来。
     ⇒ **「回撤没变」不等于「参数没影响」——它可能只是「没被触发」。**
   · **报告定稿前必须人对读一遍，抓「正文与表格自相矛盾」**：本轮首版正文写「区间内卖出一股都没有」，
     而同段表格明写 700/900 股。**这类矛盾机器自检抓不到**（表结构合法、管道数一致），
     只能靠完整通读。**结构化自检 ≠ 事实自检，两者都要做。**


34. **★ 「全量明细」重跑类任务的三条硬检查：点数口径 / 持股三口径 / 表结构逐块列数（含日志行自带管道符）** —— 2026-09-24 实例（第二十二轮，把已选方案「止盈 +30%/+60% × 卖出档 0/4/6/8 × 买入档 (1,3,5)」当单一方案跑全量并出逐期明细）：
   · **症状一：曲线「点数」与「交易日数」不是一回事。** 独立复算（第二套引擎从 CSV 重建）时，
     重建曲线比内核曲线**每个报告期多 1 个点**（14 格共多 **204** 点）——
     因为内核 `skip_anchor=True` 时对**每期锚点日**直接 `continue`，**连当日净值落点也一并跳过**。
     ⇒ **口径**：`曲线点数 ＝ 交易日数 − 报告期数`。
     补回锚点日**实测不改变任何一格的 MDD 与峰谷日**（最大 |Δ| ＝ 0.00pp）⇒ 对回撤/年化**无实质影响**，
     **但任何按点数做的统计（逐点平均、逐点回归、逐点胜率）必须先声明这一点**，
     否则等于把「每期少 1 天」当成数据。写法：核对时**显式对齐口径**
     （`pts_skip = [p for p in pts if d not in anchors]`），并把「含锚点日」的版本**另算一遍做敏感性**。
   · **症状二：持股有「三个口径」，混用即错。** `期末网格持股` ／ `累计种子存量`（`seed_cum`，
     **不含期初种子股**）／ `期末总持股`（＝ 期初种子股 ＋ 累计种子 ＋ 期末网格持股）。
     恒等式：`期末总持股 ＝ 期初种子股（A 1,000 / H 5,000） ＋ 累计种子 ＋ 期末网格持股`。
     ⚠ 并且 **「逐期沉淀流量之和 ≠ 累计种子存量」**（V2020 A：逐期沉淀合计 **36,900** 股
     vs 末期在册 **7,800** 股，差额来自**止盈卖出**）——**合计行的「流量」和「存量」并排时必须在表下注明**。
     症状：先按 `seed_cum` 出表、再按「含期初种子」出汇总 ⇒ 同一报告里出现 7,800 与 8,800 两个「期末持股」。
   · **症状三：把「本身是表格行」的外部文本嵌进表格单元 ⇒ 自带管道符，静默拆列。**
     报告 §6.5 引用重跑日志时，日志行形如 `| 记忆体积守卫（…） | ✅ 成功 | 0s |`，
     直接塞进单元格等于在该行**多出 3 个 `|`** ⇒ 表结构破损。
     **逐块列数自检会抓到**（本轮即由自检拦下，报「第 577 行起，管道数 [3,7]，共 5 行」）。
     修法：写一个 `cel(s)` —— 若文本以 `|` 开头，先按 `|` 切开取前两段再拼，
     并把残留 `|` 换成 `／`；**所有从外部文件读入、要放进表格的字符串一律过它**。
   · **症状四：负向测试应当撞「真门」，不是撞「复制品」。** 把比对逻辑在测试脚本里复制一份来测，
     测的是那个复制品。做法：给校验脚本加**可覆盖入参**（`argv[1]` 输入 JSON、`argv[2]` 输出 JSON，
     **默认行为不变 ⇒ 零漂移**），把篡改值写进**一份内核 JSON**，再 `subprocess` 调用**真正的复算脚本**，
     断言 `returncode != 0` **且**错误明细里**逐字段出现**被篡改的字段名。
     本轮一次注入 4 类篡改（逐期买入股数 +1 股 / 期末持股 +1 股 / 止盈一档次数 +1 / 曲线点数 +1），
     **4/4 字段全被报出**。
   · **症状五（治理）：正文结论必须由数据现算，不能手写。** 本轮首版手写的两句都被自己抓出错：
     「港股 V2020/V2021 年化最低」（实际 V2026 更低，只是样本不足）、
     「14 格谷底全部落在同两段时间」（表里明明有 2026-04-03 那一列）。
     **凡「哪一格最大/最小」「全部落在……」这类话，写成由 JSON 现算的循环，别手打。**
   · **症状六：跨起点年化的「递增」多半是窗口选择效应。** 把起点逐年后移，窗口会**机械地把最惨的一段甩出去**
     ⇒ 年化抬高、回撤收窄。**报跨起点年化时必须同时报「窗口是否包含那段下行」**
     （本轮：A/H 各 2 个起点含 2021-08-06 起下行、5 个不含）。**主口径取最长窗口。**


35. **★ 报告里的「定性话」必须由数据现算；且「更早/更晚」这类结论要拆开看两个维度** —— 2026-09-24 实例（第二十三轮，种子股止盈子系统的可优化空间）：
   · **症状一：把「用户描述的规则」当成「新改动」去跑。** 用户说「种子股不再受卖出档约束，只按成本价止盈，还有优化空间吗」——
     先花 5 分钟读代码/docstring（`settle_mode="residue_tp"`）就能确认**这就是现状**：
     期末 `held` 全量转台账并归零 ⇒ 下期卖出循环 `if held <= 1e-9: continue` 直接跳过。
     **别急着建新机制**；先把「它是不是已经在跑」证死，再谈空间。**结构性证据优先于跑实验**。
   · **症状二：「换一个口径后变差」有两种完全不同含义，必须分开报。**
     (a) **参数变体**（成本基准换锚点价/市价）⇒ 真的更差 ⇒ 「无空间」；
     (b) **可行性口径**（触发价从「当日最高价」换成收盘/VWAP）⇒ 业绩下降**不是**「改差了」，
     而是**原来那块收益本来就不可实现**。本轮 A 股 20.33% → 16.06%/15.98%（**≈4.35pp**）。
     ⇒ **凡报年化，必须同时报「用的是哪个价触发/成交」**；否则会把水分当成策略能力。
   · **症状三：一句话结论别写得比数据狠。** 首版写「三个自由度全部没有正向空间」，
     但 S1（到 +30% 一次清仓）在**回撤维度**是 10/1 方向一致更优 —— 只是年化中性、
     且同表 S4（0/13 更差）构成反证。稳妥写法：**「没有任何一个变体在两个维度上同时优于基准」**（可验证）。
   · **症状四：「量」相等的两档不等于「作用」相同。** 基准 14 格里 T1（+30% 卖半）与 T2（+60% 卖剩）
     次数几乎相等（95/94）⇒「分批」在本样本里**不是**「有的批只卖一半」，而是
     **把一半仓位提前在更低价格卖掉**。**报「分批有没有用」前，先看两档的触发次数比**。
   · **症状五：负向测试要撞「真门」，且要包含一项「口径错配」注入。** 只改 JSON 里的**口径标签**
     （`anchor` → `avgexp`）、**数据一个字节不动** ⇒ 复算若真按参数重算，必然报红。
     这一项能同时证明「复算不是照着数字抄」。本轮 6 项（nav1/mdd/held_end/settled_sh/p_tp_sh/口径错配）全红。
   · **症状六：独立复算出现「大面积不符」时，先怀疑自己的字段映射，不要放宽容差。**
     本轮首轮 1,663 处不符**全部**集中在 `buy_amt`，根因是内核 `p_buy_amt` **含买入费**、
     独立引擎把买费单列在 `buy_fee`。**放宽容差会把真错一起放过**；正确做法是**逐项定位**。

36. **同一个策略的「最优性」结论，会随『回测口径』与『判据』双双翻转——必须两两交叉报**
     第二十四轮的实例：R-01（种子止盈 +30%/+60% × 卖出档 0/4/6/8）在 A 股
     - 「当日**最高价**触发止盈」（乐观）下，V2020 单格年化 **20.33%**，121 组里排 **1/121**；
     - 换成「**收盘价**触发」（可实现）后，同一格 **16.06%**，排名掉到 **75/121**；
     - **但**换成「7 个起点年化中位」聚合判据后，R-01 在 `close`/`vwap` 下**都是 1/121**。
     两个判据结论**相反** ⇒ 写「A 比 B 更优」时，**必须同时写明（i）触发口径（最高价/收盘价/VWAP）、
     （ii）起点口径（单起点 or 跨起点聚合、聚合用什么统计量）**，否则该结论不可复核、也无法被推翻。
     同理，「乐观口径虚高了多少」也不能只报单起点数字：本轮 7 起点区间从 **−4.27pp 到 +7.12pp**，
     把它写成「一律虚高 4.35pp」就是过度一般化。**判据选择往往比口径本身更能决定结论方向。**

37. **把研究数据导出成 Excel 交付时的两个坑**（2026-09-24 第二十五轮，首次做 xlsx 交付。两个都是「表结构自检抓不到、回读也抓不到、肉眼看才现形」的交付层问题）：
   - **① 合并单元格 Excel 不会按内容自动调行高** —— 用 `ws.merge_cells()` 铺长说明行（标题条、口径注记、引用纪律、免责），即使设了 `wrap_text=True`，Excel 打开时**不会**自动增高，文字被截一半。**治法**：长说明行**不要合并**，写成单格（A 列）、左对齐、**不换行** —— Excel 会把文本自然溢出到右侧空列、显示完整；只有「短标题条」才用合并 + 显式 `ws.row_dimensions[r].height = N`。
   - **② 标题里写死的规模数字会跟实际不符** —— 本轮首版标题写「逐期明细（3 口径 × 14 格 × 24 期）」，实际 **612 行**：**各起点剩余的报告期数不同**（V2020 24 期 → V2026 3 期，合计 204 格期 × 3 口径 = 612）。**治法**：标题里的规模数字一律**由数据算出**（如 `sum(len(c["periods"]) for px in PX for c in G["p_cells"][px])`），不写字面常量；写完再回读对撞行数一次。
   - **通用**：xlsx 交付同样要走「生成器 → 独立回读对撞 → 负向测试」三段；**回读脚本要能接受外部文件路径**（`sys.argv[1]`），否则负向测试没法注入被篡改的副本。

38. **用户给了一个「本金数字」，先核参数、别急着改。** 说「只有启动资金 50 万」时，先 grep 内核里的资金常量
    （本案 `G.CASH_A`/`G.CASH_H`）：两者本就 = 500000（币种分开）⇒ **现状即所求**，改参才是错的。
    ★ 更要紧的是查清**本金之外还有没有其它期初持仓**：本案锁定种子股（A 1,000 / H 5,000 股）
    **不占用 `cash0`**，`nav0 = seed × px0 + cash0` ⇒ **期初总资产 ≠ 本金**（A 54.1~62.9 万 vs 50 万）。
    只报本金会让用户误以为「全套只投了 50 万」。

39. **金额账本必须多报两个比率口径看不见的指标，且回撤金额的峰值要取对。**
    ① **相对本金最差** `min(nav)/nav0 − 1`（≠ 相对峰值回撤 `mdd`；本案 A −36.22% vs −46.09%，
    H −38.94% vs −45.84%，**含义与排序都不同**）；② **期末现金占比**（本案 28%~42% ⇒ 年化只作用在六成仓位）。
    ★ 算**回撤金额**时，峰值必须取**「回撤发生那一刻」的峰值**，不是曲线最终峰值——
    谷底后又创新高时两者差得极远（本案首版把 A V2020 的 273,354 元算成 **1,505,506 元**）。

40. **两个四舍五入后的金额相减 ≠ 显示的差。** 报告里写「A 1,841,295 vs B 1,494,600，差 346,694」，
    读者一减就发现差 1 元。**显示用差值必须「先各自取整再相减」**（`round(a) - round(b)`）。

41. **xlsx 独立回读校验的文本断言要扫全表所有列，且关键词与生成器逐字一致。**
    本案「说明与校验」表是**多列**（参数名 | 值 | …），首版断言只扫第 1 列 ⇒ 4 处关键内容**假红**
    （内容其实在第 2 列）。另：断言关键词必须与生成器里的**实际用词逐字相同**
    （「禁止相加或**用**汇率互折」而非「禁止相加或汇率互折」）。

42. **双目标寻优必须先声明「免费午餐」判据，且把「0 组」当结论交付。**
    用户问「什么策略年化最高、回撤最小」时，不要只报两个极值解（那必然是两个不同方案，
    且浅回撤那个往往「几乎不持仓」）。正确做法：事前声明 **K1（年化跨起点 ≥12/14 为正）**
    与 **K2（回撤跨起点 ≥12/14 不变差）**，然后报 **K1∧K2 ＝ 0 组** —— 把「不可兼得」当作
    确定的交付结论，而不是当作搜索失败。

43. **「回撤最浅」通常是口径陷阱：一定要与参与度同读。**
    本案回撤最浅解 `+15/+30 × 浅+ × 前重 × 紧 × 回归即清`，A 回撤 −11.27% 而年化仅 16.21%，
    H 回撤 −16.54% 而年化仅 1.82% —— 机制是**几乎不持仓**。回撤小是因为「没参与」。
    ★ 报回撤必须同时给**交易笔数**与**期末现金占比**。

44. **短样本起点（<1 年）的年化是被放大的，必须报 `years` 与期数，并跨起点复核。**
    本案 V2026 仅 0.70 年 / 3 期 ⇒ 年化放大 **1.43×**。判据：把「年内最优」拿到其余起点跑一遍 ——
    本案 H 的「年内最高」在其余 6 个起点**全部跑输基线（1/7）**，直接判为拟合噪声。

45. **xlsx 独立回读校验的三个反直觉点。**
    ① **表格行不能用「列值 ∈ 集合」筛**——一个工作表里常有多个表格，下一个区块的同名列会被
    一起吃进来（本案「自变量」列在 A 区块与 B 区块都存在，行数 182 vs 应为 156）。
    改用「**表头行之后的连续非空行**」（区块之间必有空行）。
    ② **`pos += cond` 得 int（0/1 累加）**，别把它塞进 `len()`；期望行数要用
    `sum(sum(len(sub) for sub in ...))` 这种真正嵌套的写法。
    ③ **`BAD` 列表里可能含 `date` 对象** ⇒ `json.dump(..., default=str)`；并且**打印诊断必须在
    写盘之前**——否则一旦崩在序列化，rс≠0 但**全部诊断被吞掉**，负向测试的 `want in out` 必然假红。

46. **条件概率的分母是「条件事件发生的样本数」。** 写成「样本总数」会把 P(A∧B) 当成 P(B|A)：
   实测 A 股「上期涨」11 次时算成 6/22=27%，正确是 6/11=55% —— 结论从「强均值回复」翻成「无预测力」。
   报条件概率**必须同时报分母**。

47. **「对数价格水平」的 lag-1 自相关≈0.87 是随机游走的典型值，不是「趋势」证据。**
   要测趋势/回复，必须用**对数环比（收益率）**，不是价格水平。标签写「环比」而实传「水平」是最隐蔽的一类自欺。

48. **任何「逐期换策略」的 Δ，都必须先扣掉「固定同值」的 Δ（水位效应）。**
   不扣的后果：本轮 6 条档位切换规则全部 13~14/14 为正，看着像重大发现；
   实际「固定浅档」不用任何状态信息就有 +6.33pp / 13 格，切换增益 ≈ 0。
   **配套动作：打乱状态标签做安慰剂，报 z 值。**

49. **★ 校验脚本自己也会「假通过」：从 JSON 取错字段 ⇒ 对撞退化成「两个恒等容器相等」。**
   2026-09-26 第二十八轮实例：零漂移对撞脚本原本写
   `bb = B.get("cells", B)`，而该 JSON 实际结构是 `{"det":{120 项},"fp":{120 项}}`
   ⇒ `.get("cells")` 落空后拿到的是**顶层 dict 本身**，
   于是「对撞」变成比较 `B` 与 `A` 这两个**必然相等的容器**，
   ***打印出「2 格对撞 ｜ 逐格相同 2」并 exit 0*** —— 看起来全绿，实则**一格都没比**。
   **识别信号：对撞/校验的「样本数」与你预期的规模不符**（这里应 120 却报 2）——
   *这个数字本身就是 bug 的指纹*，看到就先怀疑取值路径，别急着当通过。
   **两条硬规矩**：① 取值后**断言规模**（`assert len(bb)==120`），规模不符即失败；
   ② 校验器与生成器**不得共用同一条取值假设**（否则同错同绿），
   回读/对撞要走**独立路径**并打印实际样本数。

50. **★ 敏感性/替代参数分析若「就地改写标签」，必须在每个变体后复位，否则变体会污染主判据。**
   2026-09-26 第二十九轮实例：形态分类脚本先按主判据（DIR 阈 0.50/0.75）打标，
   紧接着跑两个替代阈值（0.40/0.70、0.60/0.80）**就地覆盖**同一个 `shape` 字段，
   然后才落盘与打印 ⇒ **存下来的和打印出来的都是「最后一个变体」的标签**：
   A 股分布显示 ④12/⑤6，实际主判据应为 ④13/⑤6（边界期 Q2·2026 的 DIR=0.7748，
