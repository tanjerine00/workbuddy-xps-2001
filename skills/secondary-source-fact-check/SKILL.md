# 核证二手/转述类分析

## 何时用

用户丢来一段**不是一手材料**的东西——AI 生成的分析、自媒体深度帖、研报摘要、论文解读、
"产业链梳理/受益标的"文章——并问"分析一下""有多少接近真相""对不对""能不能成为价值的一部分"。

典型触发语：`分析`、`大白话，有多少接近真相`、`怎么评价，实事求是专业不迎合`、`成为价值的一部分`。

## 铁律：转述层默认不可信

**二手材料里的每一个"具体断言"都是待验证项，不是前提。** 尤其这几类：

| 类型 | 高发错误 | 本次实例 |
|---|---|---|
| **发表载体** | 预印本平台被写成正式期刊 | 何庭波论文实为 **ChinaXiv 预印本**，转述写成 "Science China Information Sciences 正式发表" |
| **版本数** | 只数到前一版，漏掉把结论从推测抬到确认的那一版 | 论文共 **3 版**（V1 05-25 / V2 07-03 / **V3 09-04 首披露量产实测**），转述只数到 V2 |
| **因果被加工成绝对** | 把"某约束"夸成"必须/就要求" | 论文约束是 **gear ratio < 3**，转述写成"两层折叠就必须背面供电"（查不到依据） |
| **双语报道矛盾** | 只读中文转译，不知与英文原文冲突 | 三星 SF2Z 是否缺席 2026 路线图，TrendForce 英文原文 vs 中文版说法相反 |
| **口径翻转** | 供需/进出口/方向反了 | （另一项目实例）AH 溢价方向写反 |
| **单源自媒体数字被当事实** | "产业链梳理"类文章里的营收占比、独家供货、协议年限 | "华为海思占其营收 74%""5 年封测协议"——无公告可核 |

## 工作流

### 1. 先把原文里的"硬断言"抽成清单
只抽**可被外部证伪**的：文件名、标题、日期、期刊、数字、引用、因果句。
观点句（"这值得重视"）不抽。

### 2. 逐条回一手核
- 一手优先：公司公告 / 定期报告 / 交易所与监管披露 / **论文原始发布平台** / 官方新闻稿
- 用 `WebSearch` 时**把原文标题逐字作为查询串**——能命中原文即通过，命不中就要怀疑
- 论文必查：**发布平台（预印本 ≠ 期刊）+ 版本数与各版日期 + 各版新增了什么**
- 数字必查：来源 + 统计期 + 口径

### 3. 遇冲突 → **口径冲突登记表**，不做平均
这是本技能的核心动作。同日同指标出现多个数值时：

```
| 口径 | 数值 | 来源性质 |
|---|---|---|
| 出货量口径 | X | 自媒体【未交叉验证】 |
| 收入口径 | Y | 券商转述【未交叉验证】 |
```

**必须做的反推检验**：用另一组独立数据反算该比值，看是否自相矛盾。
本次实例：声称"先进制程产能占比 3.7%"，但用"先进制程 4-6 万片/月 ÷ 总产能 109.65 万片/月"
反推得 8%-12% → **自相矛盾 → 该数字不予采用，且把"分母不确定"本身写成结论**。

**绝不做**：取中间值、取"更可信的"那个、"姑且按 X 算"。

### 4. 找那件"已经被证实的事"
转述材料往往**把推测写在标题、把已确认埋在正文**。要反过来：
> 本次实例：全文焦点是 BSPDN（【推测】级，三家公司均无回应）；
> 真正的【已确认】是"麒麟2026 已量产出货、中芯 N+2 代工、DUV 光刻、华为称没用新光刻工艺"
> —— **后者才是该材料的真正价值点**。

判断标志：**看有没有"已经卖出去的实物/已披露的财务数字"**。有 → 【已确认】；只有"据报/消息人士" → 【推测】。

### 5. 从"技术信号"桥到"财务科目"（**用户最需要这一步**）
不要停在技术讨论。逐环节问：**量？价？成本？时间？**

```
能否增产能 → 能否增出货 → 能否提 ASP → 能否降本 → 何时量产
```
逐项标"能/否/未知"。**若多数是否定或未知 + 一项负向 → 明确写"现阶段谈增厚利润无依据"。**

再找**它真正影响的那个科目**。本次实例：中芯先进制程是"能否存续"，而压制它的是**折旧**
→ 找到一个**可季度化跟踪的代理科目**：**合并报表「少数股东损益」**（非全资先进制程主体的盈利）。
> 产出规则：**每次核证都要尽量给用户挖出一个"能持续盯的数据科目"**，这比结论更有长期价值。

### 6. 价值捕获归属：查"谁能被量化绑定"
把产业链各环节按"是否有可核实的量化订单/供货披露"分级。
**某环节只有定性描述、没有量化绑定 → 该环节大概率不是价值捕获方。**
本次实例：量化绑定全在封测（长电、盛合晶微）与设备（中微、拓荆），中芯仅"提供平台"。

### 7. 三情景 + 里程碑 + 证伪条件
情景触发条件必须**可观测**（公告、财报科目、产品拆解、专利）。
必须包含一条**反直觉情景**：**技术走通但经济性不成立**（本次实例的情景 C）。
> 提醒自己：**技术验证成功与价值增加不是单调关系。**

## 输出结构（固定，便于半年后横向对比）

1. 结论先行（编号，每条带证据等级）
2. 事实核证：逐条验真 + **纠错单列**（写清"原分析称 X，实际 Y，证据 Z"）
3. 口径冲突登记（不做平均）
4. 价值传导链：逐环节量/价/成本/时间 + 真正影响的科目
5. 量级边界：**能算的** vs **算不了的**（算不了的不许估算填补）
6. 三情景（6-24 个月）+ 触发条件
7. 里程碑信号表（含可拉取的量化指标）
8. 证伪条件
9. 待核清单
10. 后续验证方向

## 易错点

- ❌ 用中文转译版做事实核验（原版可能是另一套说法）
- ❌ 把"研报预测"写成事实 → 标【市场观点】并**并列不同券商的预测**（本次实例：同一年归母净利，
  两家券商差 2 倍以上）
- ❌ 只核观点不核数字；或只核数字不核**载体/日期/版本**
- ❌ 把"产业链梳理"文章里的个股推荐数据当真 → 这类文章有荐股动机，全部降级
- ❌ 核完了不接价值（用户要的是"成为价值的一部分"，不是"事实清点"）
- ❌ 市值/总股本类数据不做算术反推（除以股价看隐含股数是否等于总股本）→ 本次实例抓到 6158 亿元与
  总股本不符，标为待核
- ❌ **「居首/第一/最大」这类排名断言不重排一遍就采信** → 见 §「排名类断言的专项检法」
- ❌ **把方法论文档当事实核**：转述里的「X 就是看 Y」往往是**未经验证的方法**，需单独判定

## ★ 排名类断言的专项检法（新增，实测抓错率极高）

**「谁最大」最容易被漏掉，因为漏掉的东西恰好是不认识的名字。**

**必须做的两件事**：
1. **自己重新排序**，不要接受转述的「居首」；
2. **按实体名称聚合**，而不是按行。**同一法人可能占多个账户/席位**，只取首行就会漏掉更大的那个。

**实证（港交所 CCASS，2026-09-20）**：转述称「中银国际居首 7.18%」。真实榜单：

| 排名 | 主体 | 持股 |
|---|---|---|
| 1 | `A00003`（中国证券登记结算） | 14.47 亿 |
| 2 | `A00004`（中国证券登记结算） | 10.12 亿 |
| **3** | **中银国际** | **6.15 亿（7.18%）** |

→ 中银的**数字完全正确**、**排名完全错误**。漏掉的两个席位属同一法人（沪/深港通分开登记），
合计占已发行 28.73%，是真正的第一。
→ **规律：被漏掉的往往是「同名多账户」或有多个口径名的机构**（清算机构、托管行、简称/全称不一致）。

## ★ 用「分母反推」同时验真伪与口径（成本极低，强烈建议每条百分比都做）

拿**独立已核证的基数**反算 `数值 ÷ 公布的百分比`，看反推出的分母落在哪个已知口径上：

```
6.15亿 ÷ 7.18% = 85.66亿  → 总股本口径 ✅（与独立核证的 85.61 亿吻合）
24.59亿 ÷ 40.89% = 60.14亿 → H 股口径   ✅（与独立核证的 60.14 亿吻合）
```

**一次得到两个结论**：数字是真的；百分比用的哪个分母。
**反推不出任何已知基数 → 该数字不予采用**（若只是口径不明则标"口径未明，暂不采用"，不要猜）。
**同时必须警惕转述对分母的沉默** —— 同一持仓「占 H 股 40.89% / 占总股本 28.72%」，
**混用会得出相反印象**，而转述通常不写分母。

## ★ 区间标签要重算（「季度」「近一年」这类词最不可信）

转述给的**区间名称**与**实际起止日**常不一致，而数字对不上时，先怀疑区间、再怀疑数字。

**实证**：转述称「华虹**季度**净流出 79.0 亿港元」。按自然季度（7/1–9/18）实为 **−116.47 亿**；
逐日扫起点后发现 **起 2026-06-09 → 09-18 = −79.60 亿** —— **数字是真的，「季度」这个标签是松的**（实为约 3.3 个月）。

→ **处置规则**：数字采信，**但引用时必须写明确切的起止日**，并把标签错误单列。
→ **方法**：不要只算一个窗口就下结论说"对不上"，要**扫一串起点**，区分「数字造假」与「区间标签不准」——
这两者的处置完全不同。

## ★ 用「收入侧隐含汇率」当尺子：区分「口径不同」与「数据错」（一次定位成功）

**场景**：A+H 两地上市公司的**同一期利润**，外部材料给的美元数与你自有的人民币数对不上。
最容易误判成「汇率算错了」或「数据造假」—— **两个都错**。

**做法**：把外部材料的美元数换算成**隐含汇率**，拿去比**自有、已交叉验证的汇率序列**。
只要同一份材料里**收入侧**与自有序列吻合，就能一次得到三个结论：

1. 该材料的**数字来源可信**（不是编的）；
2. 同一张利润表内**收入与利润不可能用两个汇率** → 利润侧对不上**只能落在「准则口径」或「利润金额」上**；
3. 去查该公司的**准则差异**，即可定性。

**实证（A+H 双重披露）**：外部材料 H1 归母 **6.77 亿美元**、H1 收入 **55.11 亿美元**。

| 侧 | 隐含汇率 | 与自有序列 |
|---|---|---|
| 收入（Q1/Q2/H1） | **7.0272 / 6.9920 / 7.0105** | ✅ **全中** |
| 利润（H1 / Q2） | **6.5989 / 6.4848** | ⚠ **系统性偏低** |

→ **不是汇率问题**。判为 **A股/CAS/人民币 ↔ H股/港交所/美元 两套披露口径**（H1 归母差 **6.2%**）；
→ 处置：**并列登记、不取平均、不判谁对**，并把「一手准则差异调节表」列为**最高优先待核项**。

**由此固化的三条纪律：**

1. **引用利润 / 毛利率 / 净利率，必须写明是哪一套披露口径** —— 与「市值三口径」同级。
   实证：单季毛利率 Q1 **21.48%（A股）↔ 20.1%（H股）**、Q2 **24.56% ↔ 25.3%**，
   **差异不是常数、方向还会翻转** → 「毛利率环比跳升」在 H 股口径是 **+5.2pct**、A 股口径是 **+3.088pct**。
2. **汇率类假设先查"是不是过时值"**。本次外部材料用 `HKD/CNY 0.913`、`USD/CNY 7.16`，
   而当日实际为 `0.8633 / 6.7698`（人民币已升值约 5.8%）→ 由其推出的 **A/H 溢价低估 11.55pp**。
   **判据（成本极低）**：把该汇率丢回自有的逐日序列里**定位"最近一次出现是什么时候"** ——
   若最近一次落在**上一年**，基本可判为**沿用旧值**。
   （本次：0.913 最近出现在 2025-11~12；7.16 在整个窗口内**从未出现**。）
3. **区分「披露性错误」与「数据造假」**。本次正文数字全对（收入侧隐含汇率全中），
   错的是**附录假设**与由它推出的派生量（溢价、人民币市值、前瞻 PE）。
   → 处置是**纠错并保留正文**，**不是否定整篇**。反之若正文数字也错，才升级为可信度问题。

**反向也成立**：若**收入侧就对不上**自有序列 → 先怀疑**区间标签 / 币种 / 单位**，
回到上一节「区间标签要重算」，**别急着定性为口径**。

## ★ A+H 双重报表公司：先问"这是哪张报表"，再问"谁错了"（新增 2026-09-22，实测）

**场景**：标的在 A 股与港股两地上市，两份财报的**记账/列报货币不同**（本例：A股 CAS 人民币 ↔ H股 IFRS 美元）。
外部材料引用的是另一张报表的数字 → 表面"打架"，实为**两套报表**。

**步骤**：
1. **先拿官方《境内外会计准则差异调节表》**（A 股半年报/年报「第七节」或附注「补充资料」）。
   它一次给出 **CAS ↔ IFRS 的净利润差异 + 净资产差异 + 逐项成因** —— **裁决级证据**，优先于任何推算。
2. **差异很小而数字仍对不上 ⇒ 差异在货币/列报，不在准则。**
   本例调节表只调 **+4.1546%**（联营企业股权被动稀释），**净资产差异为 0**。
3. **用"隐含汇率谱系"检验两套报表能否互折**：逐科目做 `A股值 ÷ H股值`。
   本例**逐层不同**（收入 7.0104 ／ 总资产 6.8175 ／ 归母 6.60-6.88 ／ OCF 6.4730）⇒ **不存在可互折的单一汇率**，**禁止折算**。
4. **找"盈亏平衡层"区分"列示口径"与"数错"**：本例两报表在「营业利润」层残差 **91 千元（≈0）**，
   差额恰等于"A股计入营业利润、H股列于其后"的那批项目（投资收益＋公允价值变动）。**差≈0 是格式；差非 0 才是数错。**
5. **同币种比值必须相同 ⇒ 可当反证工具**：毛利率 = 毛利/收入，**与货币无关**。
   若两口径毛利率不同（本例 A股 23.2% / H股 22.94%），则**两套报表的收入或成本必不相同** ⇒ 它们不是折算关系。
6. **不判谁对**：本例公司**自己就双披露**同一期间的毛利率。**跨口径引用必须写明报表来源**。

**易错点**：
- 别用汇率把一边折成另一边再比较 —— 汇率的隐含值本身逐层不同，折算会**造出假差异**。
- 别因为"数字对不上"就判造假；**先穷尽口径**（本项目已在"市值三口径"上踩过三次）。
- 反向：官方调节表**只调准则差异，不覆盖货币折算层** —— **拿到调节表 ≠ 两套报表即可互折**。

## 与其它技能的分工

- 本项目有数据管道时，**财务数字要走 `ashare-data-crossvalidation`**（东财主 → 万得次 → 新浪/腾讯验证），
  不要用 WebSearch 的数字当财务依据。
- 本技能只管**非结构化/转述类信息**的核证与价值桥接。
